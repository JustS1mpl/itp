# Удобство на телефоне (7.0, фаза 4)

Ученик часто решает задачи с телефона. Главное, что мешало: на экранной клавиатуре нет скобок, двоеточия, кавычек и Tab на первом экране, а сама клавиатура закрывает строку, которую набираешь, и кнопку «Проверить».

## Что сделано

| Что | Как | Почему так |
|---|---|---|
| Полоска символов | Над клавиатурой, только на сенсорных экранах (`!KBD`), пока поле кода в фокусе: ⇥ ⇤ ← → ( ) : " ' = [ ] { } + - * / % < > # _ , . Листается вбок. | Самые частые в Python знаки идут первыми, стрелки нужны, чтобы выйти из закрытой скобки без точного тычка пальцем. Скобки и кавычки закрываются парой, как при наборе с клавиатуры (настройка «Закрывать скобки и кавычки»). |
| Фокус не теряется | Кнопки полоски гасят `pointerdown`/`mousedown`, при потере фокуса поле возвращается. | Иначе клавиатура закрывается после каждого символа. |
| Клавиатура не закрывает код | Высота клавиатуры берётся из `visualViewport`; полоска встаёт прямо над ней, строка с курсором прокручивается выше полоски после каждого ввода. Снизу у страницы появляется запас 72 px. | `position:fixed` в Chrome для Android и Safari остаётся под клавиатурой. |
| «Проверить» не мешает | Пока пишешь код на телефоне, нижняя панель скрыта (`html.kbo .dock`) и возвращается, когда клавиатура закрыта. | Две закреплённые полосы над клавиатурой оставляют для кода 3–4 строки на 360×640. |
| Вернуть начальный код | Кнопка ↺ в шапке редактора у заданий, проектов и случайного кода; спрашивает подтверждение. | Раньше черновик можно было только стереть руками. |
| Шрифт | Размер кода S/M/L/XL — в настройках (уже был); на сенсорных экранах не меньше 16 px, иначе iOS увеличивает страницу при фокусе. Лигатуры моноширинного шрифта выключены (`>=` не превращается в `≥`). | |
| Подсказка «Ctrl + Enter» | Показывается только при мыши и клавиатуре. | На телефоне её нечем нажать. |
| Условие задачи | Обычный вес текста, крупнее (17 px, межстрочный 1,55); точные строки вывода в «ёлочках» — моноширинным шрифтом на подложке. | Ученику проще увидеть, что именно надо вывести. |

## Проверка

`tests/mobile7.py` (Playwright, сенсорный режим) на 360×640, 390×844, 412×915, 768×1024 и 844×390: нет горизонтальной прокрутки на вопросе, задании и проекте; полоска появляется и прячет нижнюю панель; ⇥, (, ", ), : вставляют `    print("x"):`; ⇤ и ← работают, фокус остаётся в поле; после 30 строк курсор над полоской; сброс возвращает шаблон; ошибок в консоли нет.

Не проверить в Playwright: настоящую экранную клавиатуру (её высоту даёт только живой телефон). Нужно глазами на Android и iPhone.

## Не сделано (на потом)

- Вкладки «Условие / Код / Вывод» для очень длинных задач — длинные условия уже сворачиваются, решили не дробить экран.
- Отдельная раскладка для горизонтального телефона — на 844×390 всё помещается, полоска не мешает.
