# PRODUCT.md: ИТП («И так, программирование»)

Написано вручную: плагин Impeccable (`init`) в этой среде недоступен.

**Что это.** Одностраничное приложение для изучения Python для подростков 15–16 лет. Один HTML-файл, работает без интернета, Python внутри браузера (Pyodide).

**Для кого.** Школьники, которые учат Python сами и на уроках. Короткие сессии на телефоне, чаще в движении и вечером (тёмная тема).

**Что главное.** Понятный путь: на каждом экране одно главное действие. Теория подробно с выводом, задания только на объяснённый материал, ошибки мягкие и полезные (разбор ошибок, словарь, статистика ошибок).

**Тон.** Дружелюбный и спокойный, без упрёков и без детскости. Кролик-талисман появляется только в настоящие моменты награды или реальной ошибки.

**Не делаем.** Копию чужого приложения, фоновую «возню» (мерцание, зацикленные анимации), нагромождение кнопок, звук на каждый мелкий жест, картинки/аудио/видео файлами (всё кодом: SVG, CSS, JS, Web Audio).

**Нельзя ломать.** Нижняя панель Путь/Практика/Код/Профиль; острова-шестиугольники; настройки по нажатию на «ITP»; светлая и тёмная темы; XP, подсказка 50 %, серия, заморозка, цели дня, календарь, вопросы-вспышки, разбор ошибок, словарь; пасхалка (12 нажатий по версии) и режим разработчика; цвета функций; встроенный Python с принудительной остановкой; сохранённый прогресс; система добавления тем (`Темы_N.txt`, `TOPICS/FILESETS`, `docs/prompt_for_ai_v5.7.0.md`).
