# ИТП: выпуск для телефона (APK / Google Play) и ПК (.exe)

Это план, а не инструкция «нажми сюда». Файлы APK и EXE пока не создаём. Цены, сроки и требования магазинов меняются
каждый год — то, что помечено ⚠️, проверь в день выпуска.

ИТП — один HTML-файл, который работает без интернета: Python (Pyodide) встроен, прогресс хранится в `localStorage`.
Поэтому и телефон, и ПК — одно и то же: **окно-браузер (WebView), в котором открыт `ИТП.html`**. Новый код писать не
нужно, только «обёртку» и несколько доработок (раздел 4).

---

## 1. Что выбрать

| | Телефон (Android) | ПК (Windows) |
|---|---|---|
| **Рекомендую** | **Capacitor** — кладёшь HTML в папку, получаешь проект Android Studio | **Tauri 2** — .exe/установщик ~5–10 МБ, окно на встроенном в Windows движке Edge (WebView2) |
| Запасной вариант | Trusted Web Activity (PWABuilder / Bubblewrap) — но нужен сайт с приложением в интернете | **Electron** — всё ставится через npm, без Visual Studio, но .exe ~90–150 МБ |
| Что ставить | Node.js, Android Studio (с ним JDK и Android SDK) | Tauri: Node.js, Rust, Visual Studio Build Tools. Electron: только Node.js |

**Про «только диск E».** Node.js, Rust (`RUSTUP_HOME`, `CARGO_HOME`), Android SDK, Gradle (`GRADLE_USER_HOME`) и
npm-кэш можно поставить на E. Visual Studio Build Tools (нужны Tauri) частично всё равно ставятся на C — если это
недопустимо, бери Electron.

## 2. Телефон: Capacitor → APK и AAB

1. Папка проекта, например `E:\Program Files\itp-app\`:
   ```
   npm init -y
   npm i @capacitor/core @capacitor/cli @capacitor/android
   npx cap init ИТП app.itpcode.itp --web-dir www
   ```
   `app.itpcode.itp` — **имя пакета. Оно навсегда**: после публикации его не поменять, только выпустить новое
   приложение с нуля.
2. Скопировать сборку: `ИТП.v7.x.html` → `www/index.html`.
3. `npx cap add android`, потом `npx cap open android` — откроется Android Studio.
4. Иконка и заставка — `npx @capacitor/assets generate` из одной картинки 1024×1024 (кролик).
5. Проверка: в Android Studio кнопка ▶ на телефон по USB (включить «Отладку по USB»).
6. Выпуск: **Build → Generate Signed App Bundle / APK**.
   - **AAB** — для Google Play (магазин принимает только его).
   - **APK** — чтобы раздавать файлом самому или в другие магазины.
   - Для подписи создаётся **ключ (keystore)**. Сохрани файл и пароль в двух местах (например, флешка + облако).
     Без него не выпустить обновление в других магазинах. В Google Play при потере можно сбросить ключ загрузки через
     поддержку, но это неделя-две.
7. Каждый выпуск: в `android/app/build.gradle` поднять `versionCode` (целое, +1 каждый раз) и `versionName`
   (например `7.0.0` — как `VER` в `build5.py`).

## 3. Google Play: по шагам

1. **Аккаунт разработчика** — play.google.com/console. Разовый взнос ⚠️ $25. Тип «Личный». Нужен паспорт для проверки
   личности, адрес, телефон. Если тебе меньше 18 — аккаунт оформляет родитель/опекун на себя.
2. ⚠️ **Закрытое тестирование для новых личных аккаунтов.** Прежде чем выпустить приложение для всех, Google требует
   закрытый тест: **не меньше 12 тестировщиков, которые не удаляют приложение 14 дней подряд**. Потом подаётся заявка
   на «рабочую версию». Начни собирать 12 человек (друзья, одноклассники) заранее — это самый долгий шаг.
3. **Создать приложение** в консоли: название «ИТП — И так, программирование», язык русский, «Приложение», «Бесплатное».
4. **Страница в магазине**:
   - иконка 512×512 PNG;
   - картинка-баннер 1024×500;
   - скриншоты телефона: минимум 2, лучше 4–8 (Путь, теория, задание с кодом, профиль);
   - короткое описание (до 80 символов) и полное (до 4000).
5. **Обязательные анкеты** (раздел «Контент приложения»):
   - **Политика конфиденциальности** — ссылка на страницу. Нужна всем приложениям. Можно сделать на GitHub Pages:
     «Приложение не собирает и не передаёт данные; прогресс хранится только на устройстве; связь — почта».
   - **Безопасность данных (Data safety)** — честно отметить: данные не собираются и не передаются. Это так: всё в
     `localStorage`, сети нет (кроме ссылок, которые человек открывает сам).
   - **Возрастной рейтинг (IARC)** — анкета, получится «3+»/«Для всех».
   - **Целевая аудитория.** ⚠️ Если отметить возраст **до 13 лет**, приложение попадает под правила «Для семей»
     (Families): строже проверка, обязательные требования к рекламе и данным. Рекламы и сбора данных у ИТП нет, так
     что пройти можно, но проще и быстрее — **13+**.
   - Реклама: «нет». Доступ для проверки: «без входа в аккаунт».
6. ⚠️ **Целевой уровень Android.** Каждый август Google поднимает минимальный `targetSdkVersion` для новых приложений и
   обновлений (в 2025 — Android 15 / API 35, с конца августа 2026 — Android 16 / API 36). Свежий Capacitor выставляет
   его сам, Play Console покажет ошибку, если он устарел.
7. Загрузить **AAB** в «Закрытое тестирование» → добавить тестировщиков по почте → через 14 дней «Рабочая версия».
   Проверка Google обычно от нескольких часов до нескольких дней.

### ⚠️ Если ты в России

Оплатить взнос Google Play российской картой нельзя, а аккаунты с российскими данными часто не проходят проверку.
Варианты:
- **RuStore** (rustore.ru) — бесплатная регистрация, принимает тот же APK/AAB, на многих телефонах уже стоит;
- **AppGallery** (Huawei), **Galaxy Store** (Samsung), **Xiaomi GetApps** — бесплатно;
- **APK файлом** — на своём сайте / в Telegram-канале. Человеку нужно разрешить «Установку из неизвестных
  источников». ⚠️ Google вводит обязательную проверку разработчиков и для приложений вне Play (с 2026 года, сначала
  в нескольких странах) — для своих же пользователей это пока не мешает, но следи за новостями.

## 4. Что доработать в самом ИТП перед обёрткой

В обычном браузере это работает, а в WebView — нет или по-другому:

| Что | Проблема | Решение |
|---|---|---|
| **Резервная копия** (сохранить файл), сохранение картинок «Поделиться» и «Я могу…» | `<a download>` и blob-ссылки в Android WebView ничего не скачивают | Capacitor-плагины `@capacitor/filesystem` + `@capacitor/share`: записать файл и открыть системное «Поделиться». В Tauri — плагины `dialog` + `fs` («Сохранить как…») |
| **Поделиться** картинкой | `navigator.share` в WebView обычно нет | `@capacitor/share` |
| **Кнопка «Назад»** Android | без обработки сразу закрывает приложение | `@capacitor/app` → событие `backButton` → вызвать то же, что Esc (`goBack`), на Пути — свернуть приложение |
| **Ссылки** (почта, лицензия, внешние сайты) | открываются внутри окна, обратно не вернуться | открывать в системном браузере (`@capacitor/browser`; в Tauri — плагин `opener`) |
| **Прогресс** | живёт в `localStorage` WebView: при удалении приложения пропадает | в первом запуске напоминать про «Резервную копию»; в Android включить Auto Backup (`android:allowBackup`) |
| **Версия** | — | показывать «7.0.0» без `-dev`; брать из того же `VER` |
| **Слабые телефоны** | Pyodide — WebAssembly, ест память | уже есть `html.lite` и отложенная загрузка Python; проверить на самом слабом телефоне, что есть под рукой |
| **Окно ПК** | — | минимальный размер окна (например 380×600), название «ИТП», иконка .ico |

Удобно сделать один флаг в `build5.py`, например `TARGET = 'web' | 'android' | 'win'`, и подключать маленький
файл-«мостик» (`v5/a_native.js`), который заменяет скачивание/«Поделиться»/«Назад» на вызовы плагинов, а в браузере
не делает ничего.

## 5. ПК: Tauri 2 → .exe

1. Установить Rust (rustup), Node.js, Visual Studio Build Tools («Desktop development with C++»). WebView2 уже есть в
   Windows 10/11.
2. `npm create tauri-app@latest` → шаблон «Vanilla», папка фронтенда — та же `www/` с `index.html`.
3. В `src-tauri/tauri.conf.json`: `productName` «ИТП», `identifier` `app.itpcode.itp`, размер окна, иконки
   (`npx tauri icon кролик.png`).
4. `npx tauri build` → в `src-tauri/target/release/bundle/` появятся **установщик NSIS (.exe)** и **MSI**.

**Electron вместо Tauri:** `npm i -D electron electron-builder`, `main.js` открывает `www/index.html` в
`BrowserWindow`, `npx electron-builder --win nsis portable` — получится установщик и переносной .exe.

### Подпись и SmartScreen

Неподписанный .exe при первом запуске покажет синее окно «Windows защитила ваш компьютер» → «Подробнее» →
«Выполнить в любом случае». Убрать его можно:
- ⚠️ **Microsoft Store** — регистрация для частных разработчиков стала бесплатной (2025); Store сам подписывает
  приложение, предупреждения нет, обновления приходят сами. Подходит и MSI/EXE от Tauri.
- **Сертификат подписи кода** — платный (десятки–сотни долларов в год), для начала не нужен.

## 6. Порядок, который я бы предложил

1. Довести 7.0.0 (backlog: миграция сохранений S1, тесты S2), убрать `-dev`.
2. Добавить «мостик» `a_native.js` и флаг сборки (раздел 4) — это моя часть, скажи, когда начинать.
3. Android через Capacitor → проверить на 2–3 телефонах → APK для друзей.
4. Параллельно: страница политики конфиденциальности, скриншоты, тексты для магазина, сбор 12 тестировщиков.
5. Google Play (закрытый тест 14 дней) и/или RuStore.
6. Windows через Tauri → Microsoft Store или установщик на сайте.

Обновления потом — та же сборка `ИТП.html` → `www/index.html` → `versionCode + 1` → новый AAB/EXE.

## 7. Что уже сделано (dev.36)

Проект приложений — в папке `app/` репозитория:

| Что | Где |
|---|---|
| Android (Capacitor 7) | `app/android/` — проект Android Studio; `app/capacitor.config.json` |
| Windows (Electron) | `app/desktop/main.js`, `app/desktop/preload.js`; настройки установщика — `app/package.json` → `build` |
| Иконки | `app/icons/logo.png` (логотип) → `python icons/make_icons.py` делает все значки Android, значок уведомлений, заставку, `icon.ico` |
| Сборка всего | `bash app/build.sh` (после `python build5.py`) → `app/dist/android/ITP.apk`, `ITP.aab`, `app/dist/ITP-Setup-*.exe`, `ITP-*-portable.exe` |

**Ключ подписи Android** — `app/android/itp-release.keystore`, пароль — в `app/android/keystore.properties`. Оба файла
**не попадают в git** (так и надо: ключ — секрет). Сделай их копию в двух местах (флешка + облако). Для Google Play
этот ключ — «ключ загрузки», его можно сбросить через поддержку; для RuStore и раздачи APK файлом без него новую версию
поверх старой не поставить.

**Инструменты сборки** (JDK 21, Android SDK, кэши) лежат в `E:\Program Files\itp-tools` и будут удалены вместе с
ней после твоего «да». Чтобы потом собрать заново: снова скачать JDK 21 (Temurin) и Android command-line tools в
`itp-tools`, создать `itp-tools/env.sh` (пути — в начале `app/build.sh`), `npm install` в `app/`.

## 8. Название на разных языках и язык системы

**Название приложения можно менять по языку.** На Android это обычное дело: строка `app_name` лежит в
`android/app/src/main/res/values/strings.xml` (название по умолчанию), а для других языков — в
`values-en/strings.xml`, `values-uk/strings.xml` и т. д. Телефон сам покажет нужное под значком. Сейчас там «ИТП» —
добавить `values-en` с «ITP» — пара строк. В Google Play и RuStore название и описание страницы тоже задаются отдельно
для каждого языка. На Windows имя файла и ярлыка одно, но заголовок окна ИТП может ставить сам по языку.

**Определять язык по системе — да, работает.** Внутри приложения `navigator.language` (и список `navigator.languages`)
отдаёт язык телефона/Windows: на Android WebView это язык системы, в Electron — язык Windows. Правильно делать так:
1. первый запуск — язык из системы, если он есть среди переведённых, иначе английский (или русский);
2. в настройках — выбор языка вручную, и он важнее системного;
3. сохранять выбор в прогрессе, чтобы он переносился резервной копией.
Подводный камень один: у части людей система на английском, а учиться они хотят на русском — поэтому ручной выбор
обязателен, и его стоит показать в самом начале вступления.
