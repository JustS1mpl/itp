# Задание №26 — «Жадный сервер»

Нора: **ЕГЭ: код решает** · балл: 2 · на экзамене: 15–25 минут.
Что нужно из курса: чтение файла, `sort`, кортежи, словари, моделирование.

## Суть

Большой файл с записями (покупки, запросы, грузы, места в зале). Надо **отсортировать** данные и **промоделировать** процесс по правилам условия: кто куда помещается, когда освобождается память, какой ряд выбрать. В ответ — два числа.

## Как это звучит в КИМ (демо 2027)

Сервер копит данные запросов в разделе памяти объёмом K. Если очередной запрос не помещается, сервер делает резервную копию всего накопленного, очищает раздел и продолжает. Найти клиента с наибольшим суммарным объёмом и сумму двух самых больших копий, сделанных не позже 11:59:59.

## Теория

- Читаем первую строку отдельно: `n, k = map(int, f.readline().split())`.
- Время `ЧЧ:ММ:СС` сравнивать можно прямо как строки — формат фиксированной длины, `'05:05:05' < '11:59:59'` работает правильно.
- Сортировка по нескольким ключам: `data.sort(key=lambda r: (r[0], -r[1]))` — по первому по возрастанию, по второму по убыванию.
- Подсчёт по ключу — словарь: `total[c] = total.get(c, 0) + s`.
- «Жадность»: на каждом шаге делаем лучшее локальное действие (берём самый дешёвый товар, кладём в первую подходящую ячейку). Условие обычно прямо говорит, какое.

## Решение 1. Полу-ручное: проверка на типовом примере

Прежде чем запускать код на миллионе строк, прогоняешь его на примере из условия (8 строк). В демо ответ на примере — `303 220000`. Совпало — запускаешь на файле. Расхождение на примере в 10 раз проще найти, чем на реальных данных. Отдельные шаги удобно смотреть руками: напечатай список копий `backups` для примера и сверь с текстом условия (130 000, 90 000, 122 000, 120 000).

## Решение 2. Полностью кодом

```python
f = open('26.txt')
n, k = map(int, f.readline().split())
rows = []
for _ in range(n):
    t, c, s = f.readline().split()
    rows.append((t, int(c), int(s)))
rows.sort()                                  # по времени

total = {}
backups = []                                 # (время, объём копии)
used = 0
for t, c, s in rows:
    total[c] = total.get(c, 0) + s
    if used + s > k:                         # не помещается — копия и очистка
        backups.append((t, used))
        used = 0
    used += s

client = max(total, key=total.get)
early = sorted((v for t, v in backups if t <= '11:59:59'), reverse=True)
print(client, early[0] + early[1])           # 7040 52204
```

## Вариации

Сюжеты каждый год новые, но схема одна: **прочитать → отсортировать → пройти циклом по правилу условия**.

| Сюжет | Что обычно делают |
|---|---|
| Покупки на бюджет | сортировка по цене, берём дешёвые, пока хватает денег, потом пытаемся заменить последний на дорогой |
| Грузы по рядам/местам | сортировка, «первая подходящая ячейка» |
| Ряды и места в зале | сортировка по ряду и месту, ищем пары свободных мест |
| Интервалы времени (наблюдатели, пик посещаемости) | события «начало/конец», сортировка по времени, счётчик активных |
| Скидки и чеки | сортировка товаров в чеке, правило скидки на каждый |
| Отбор / конкурс | сортировка по баллам, проверка пограничного случая |
| Архив/рюкзак | сортировка по размеру, берём мелкие, пока помещаются |

Всегда сначала прогоняй код на примере из условия.
