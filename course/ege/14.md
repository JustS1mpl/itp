# Задание №14 — «Цифры после девятки»

Нора: **ЕГЭ: код решает** · балл: 1 · на экзамене: 4–6 минут.
Что нужно из курса: `int(s, base)`, `%` и `//`, `while`, строки.

## Суть

Позиционные системы счисления. Два типа вопросов:
1. **Выражение со степенями**: «значение 4·625²⁰ + 3·125⁴⁰ − 2·25³⁰ … записали в системе с основанием 5; сколько в записи цифр 4?»
2. **Неизвестная цифра x** в записи чисел с основанием больше 10: «найдите наименьшее x, при котором сумма делится на 21».

## Теория

- `int('27x98876', 22)` переводит строку из системы с основанием до 36 в десятичное число. Цифры старше 9 — буквы: A=10, B=11, … Удобный «алфавит цифр»: `'0123456789abcdefghijklmnopqrstuvwxyz'`.
- Обратно, из десятичного в основание b, — делением с остатком:

```python
def to_base(n, b):
    digits = []
    while n > 0:
        digits.append(n % b)     # младшая цифра
        n //= b
    return digits[::-1]          # список цифр, старшая первая
```

Список, а не строка, потому что основание бывает больше 36 и «букв» не хватит. Количество цифр 4 — `to_base(n, 5).count(4)`.

## Решение 1. Полу-ручное: степени в уме

625²⁰ = 5⁸⁰, 125⁴⁰ = 5¹²⁰, 25³⁰ = 5⁶⁰. Число 3·5¹²⁰ — это `3` и 120 нулей; 4·5⁸⁰ — `4` и 80 нулей; вычитание 2·5⁶⁰ превращает хвост в ряд цифр 4 (как 1000 − 1 = 999 в десятичной). Это правило можно знать, но проще поручить подсчёт коду: Python работает с огромными числами точно.

```python
n = 4 * 625**20 + 3 * 125**40 - 2 * 25**30
print(to_base(n, 5).count(4))
```

## Решение 2. Полностью кодом: перебор неизвестной цифры

Демоверсия 2027: `27x98876₂₂ + 26x51₂₂ + 711x5₂₂`, наименьшее x, при котором сумма кратна 21; в ответ — частное.

```python
alphabet = '0123456789abcdefghijklmnopqrstuvwxyz'
for x in range(22):                       # цифры 22-ричной системы: 0..21
    d = alphabet[x]
    n = int('27' + d + '98876', 22) + int('26' + d + '51', 22) + int('711' + d + '5', 22)
    if n % 21 == 0:
        print(x, n // 21)
        break
```

Ответ — `276296118`. Если неизвестных цифр две (x и y), — два вложенных цикла. Если основание больше 36, `int` не поможет: считай число по схеме Горнера `n = n * b + digit` из списка цифр.

## Вариации

| Подтип | Как |
|---|---|
| Выражение со степенями → сколько цифр k в записи | перевод `to_base` и `.count(k)` |
| Неизвестная цифра x (или x и y) | перебор цифр, `int(строка, основание)` |
| Основание больше 36 | список цифр и схема Горнера: `n = n * b + d` |
| Найти основание системы | перебери основание, переводи число и проверяй условие |

## Ловушки

- Цифра x в системе с основанием b — от 0 до b−1. «Старшая» цифра не может быть 0, если запись не допускает ведущих нулей.
- Не переводи огромные числа через `float` — только целые.
- `'27x...'` в условии: x — не буква икс, а место для цифры. Подставляй символ из алфавита.
