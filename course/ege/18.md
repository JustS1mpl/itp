# Задание №18 — «Робот собирает монеты»

Нора: **ЕГЭ: исполнители и графы** · балл: 1 · на экзамене: 10–15 минут.
Что нужно из курса: двумерные списки, `max/min`, динамическое программирование.

## Суть

Поле N × N в электронной таблице, в каждой клетке монета. Робот идёт из левого верхнего угла только **вправо** или **вниз** и собирает монеты. Внутренние стены (толстые линии) мешают. Найти максимальную и минимальную сумму.

## Теория: динамика

Лучшая сумма в клетке = монета клетки + лучшая из сумм соседей, **откуда** в неё можно прийти (сверху и слева, если между ними нет стены). Заполняем таблицу построчно — к каждой клетке ответы для верхней и левой уже готовы.

```
best[i][j] = a[i][j] + max(best[i-1][j], best[i][j-1])
```

В первой строке есть только сосед слева, в первом столбце — только сверху.

## Решение 1. Полу-ручное: формула в Excel

Это задание создано для электронной таблицы. Рядом с полем (например, начиная со столбца W) повтори его размер. В первую клетку — `=A1`, в первую строку — `=A1+W1` со сдвигом, дальше — `=МАКС(W1;V2)+B2`. Протяни формулу на всё поле. Там, где стоит стена, формулу правишь руками: если стена сверху — берёшь только левого соседа, если слева — только верхнего. Итог — в правом нижнем углу (или в «угловых» клетках со стенами справа и снизу). Для минимума — то же с `МИН`.

## Решение 2. Полностью кодом

Стены в файле — это оформление ячеек, а не данные, поэтому их обычно переносят в код руками: множество пар клеток, между которыми стена.

```python
a = [list(map(int, line.split())) for line in open('18.txt')]   # поле, скопированное в txt
N = len(a)
wall_right = {(3, 5), (3, 6)}        # стена справа от клетки (строка, столбец) — с картинки
wall_down = {(7, 2), (7, 3)}         # стена снизу от клетки

INF = float('inf')
mx = [[-INF] * N for _ in range(N)]
mn = [[INF] * N for _ in range(N)]
mx[0][0] = mn[0][0] = a[0][0]
for i in range(N):
    for j in range(N):
        if i == j == 0:
            continue
        cand = []
        if j > 0 and (i, j - 1) not in wall_right:
            cand.append((mx[i][j-1], mn[i][j-1]))
        if i > 0 and (i - 1, j) not in wall_down:
            cand.append((mx[i-1][j], mn[i-1][j]))
        cand = [c for c in cand if c[0] > -INF]
        if cand:
            mx[i][j] = a[i][j] + max(c[0] for c in cand)
            mn[i][j] = a[i][j] + min(c[1] for c in cand)
print(mx[N-1][N-1], mn[N-1][N-1])
```

С 2026 года конечных клеток бывает несколько — «угловые», у которых стена и справа, и снизу. Тогда ответ — максимум `mx` и минимум `mn` по всем таким клеткам.

Стены можно и прочитать из `.xlsx` библиотекой `openpyxl`: у ячейки есть `cell.border.right.style` и `cell.border.bottom.style` — непустой стиль значит стену.

## Вариации

| Подтип | Что меняется |
|---|---|
| Классика: из левого верхнего в правый нижний | базовая динамика |
| Несколько финишей («угловые» клетки) | ответ — max/min по всем таким клеткам |
| Другое направление (снизу вверх, из левой нижней в правую верхнюю) | переверни таблицу (`a[::-1]`) и решай как классику |
| «С северной границы до южной» | старт — любая клетка первой строки: заполни всю первую строку стартовыми значениями |
| Сначала минимум, потом максимум | порядок чисел в ответе |

## Ловушки

- В клетку под стеной «сверху» можно прийти только слева, и наоборот.
- Монета стартовой и конечной клетки тоже считается.
- Если какая-то клетка недостижима, её значение не должно влиять на соседей — поэтому `-INF`/`INF` и проверка.
