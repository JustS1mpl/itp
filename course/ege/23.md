## Суть

Файл — список рёбер ориентированного графа без циклов: `L M W` — дорога из L в M длиной W. Найти кратчайший путь из 1 в 100, самый длинный путь, количество путей, путь через обязательную вершину, наименьшее число рёбер.

## Теория

Граф — словарь «вершина → список (сосед, вес)». Раз циклов нет, работает простая рекурсия: лучший путь из v в цель = лучшее из «вес ребра + лучший путь из соседа».

```python
from functools import lru_cache

g = {}
for line in open('23.txt'):
    a, b, w = line.split()
    g.setdefault(int(a), []).append((int(b), float(w)))

INF = float('inf')

@lru_cache(None)
def shortest(v, target):
    if v == target:
        return 0
    return min((w + shortest(u, target) for u, w in g.get(v, [])), default=INF)
```

- Самый длинный: `max` вместо `min`, `-INF` вместо `INF`.
- Число рёбер: вместо `w` прибавляй `1`.
- Количество путей: `sum(paths(u) for u, w in g[v])`, база — 1.
- Через вершину c: `shortest(a, c) + shortest(c, b)`.
- Запрещённая вершина: `return INF`, если `v == bad`.

## Решение 1. Полу-ручное: граф глазами

Маленький граф из примера (8 рёбер) решается на листке: выписываешь рёбра, рисуешь, считаешь пути. Пример: из 1 можно в 7 (5,5), в 100 (12), в 4 (2,5); из 7 — в 100 (2); из 4 — в 100 (8). Кратчайший 1 → 7 → 100 = 7,5, целая часть **7**. В реальном файле до 200 рёбер — тут без кода никак, но пример из условия всегда прогоняй руками, чтобы проверить программу.

## Решение 2. Полностью кодом

```python
print(int(shortest(1, 100)))          # демоверсия 2027: 10971
```

Путь ровно из k рёбер — добавь счётчик в параметры:

```python
@lru_cache(None)
def exact(v, k):
    if k == 0:
        return 0 if v == 100 else INF
    return min((w + exact(u, k - 1) for u, w in g.get(v, [])), default=INF)
print(int(exact(1, 14)))
```

Если строк больше пары тысяч, а граф глубокий, подними лимит рекурсии: `sys.setrecursionlimit(10**5)`.

## Вариации

| Подтип | Изменение в рекурсии |
|---|---|
| Кратчайший путь | `min`, `+ w` |
| Самый длинный | `max`, `+ w` |
| Наименьшее/наибольшее число рёбер | `+ 1` вместо `+ w` |
| Количество путей | `sum`, база — 1 |
| Ровно k рёбер | добавить k в параметры |
| Через вершину, без вершины, без ребра | разбить путь на части, вернуть `INF` для запретов, выкинуть ребро при чтении |
| «Максимальный вес пути» = самое тяжёлое ребро, его минимизировать | `min(max(w, best(u)) ...)` |

## Ловушки

- Числа в строке разделены «произвольным количеством пробелов и табуляций» — `split()` без аргумента справляется.
- Вершины пронумерованы не подряд — поэтому словарь, а не список.
- «Целая часть» — `int()`, а не `round()`.
- Ориентированный граф: ребро `a b` ведёт только из a в b.
