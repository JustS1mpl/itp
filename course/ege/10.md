# Задание №10 — «Адрес твоего дома в интернете»

Нора: **ЕГЭ: код решает** · балл: 1 · на экзамене: 3–5 минут.
Что нужно из курса: `ipaddress` (из норы про IP-адреса), f-строки, `for`.
До 2025 года это было задание №13 — в старых сборниках ищи его там.

## Суть

IP-адрес — 32 бита, записанные четырьмя числами 0…255 (`192.168.159.86`). Маска — 32 бита: сначала единицы, потом нули (`255.255.252.0`). Адрес сети = адрес узла AND маска. Вопросы: найти адрес сети, число адресов в сети, саму маску по двум адресам, адреса с особым числом единиц.

## Теория

- Маску пишут и коротко: `/22` — первые 22 бита единицы. `255.255.252.0` = `/22`.
- В сети с маской `/m` всего 2^(32−m) адресов. Два из них нельзя дать компьютеру: адрес сети (все нулевые биты узла) и широковещательный (все единичные). Поэтому «узлов» 2^(32−m) − 2.
- Python знает всё это сам:

```python
from ipaddress import ip_network, ip_address

net = ip_network('192.168.159.86/255.255.252.0', strict=False)
print(net)                    # 192.168.156.0/22
print(net.network_address, net.netmask, net.num_addresses)
for ip in net:                # все адреса сети, включая два служебных
    ...
for ip in net.hosts():        # только адреса узлов
    ...
print(f'{ip_address("10.0.0.5"):b}')   # 32 бита строкой
```

`strict=False` нужен, когда даёшь адрес узла, а не адрес сети.

## Решение 1. Полу-ручное: AND по одному байту

Маска 255 оставляет байт как есть, маска 0 — обнуляет. Считать надо только «рваный» байт. Демо 2027: адрес `192.168.159.86`, маска `255.255.252.0`. Третий байт: 159 = `10011111`, 252 = `11111100`, AND = `10011100` = 156. Адрес сети — `192.168.156.0`, сумма октетов 192 + 168 + 156 + 0 = **516**.

Проверка в одну строку: `print(159 & 252)`.

## Решение 2. Полностью кодом

Демоверсия — сумма октетов адреса сети:

```python
from ipaddress import ip_network
net = ip_network('192.168.159.86/255.255.252.0', strict=False)
print(sum(map(int, str(net.network_address).split('.'))))     # 516
```

Неизвестная маска: «для узла 205.154.212.20 адрес сети 205.154.192.0; наибольшее значение третьего байта маски?» Перебираем все 33 длины маски и оставляем подходящие:

```python
from ipaddress import ip_network
for m in range(33):
    net = ip_network(f'205.154.212.20/{m}', strict=False)
    if str(net.network_address) == '205.154.192.0':
        print(m, net.netmask)
```

Подходят `/18` и `/19`; наибольший третий байт — 224.

Подсчёт адресов с условием: «сколько адресов в сети 95.24.16.0/255.255.240.0, у которых в двоичной записи единиц больше, чем нулей?»

```python
from ipaddress import ip_network
net = ip_network('95.24.16.0/255.255.240.0')
print(sum(1 for ip in net if f'{ip:b}'.count('1') > 16))
```

## Вариации

| Подтип | Как в коде |
|---|---|
| Адрес сети по узлу и маске | `ip_network(f'{ip}/{mask}', strict=False).network_address` |
| Неизвестная маска (байт маски, нули, единицы) | перебери `/0…/32`, оставь подходящие |
| Сколько адресов / узлов | `net.num_addresses` / минус 2 для узлов |
| Сколько масок возможно при условии на число узлов | перебери длины маски, считай `2**(32 - m) - 2` |
| Адреса с условием на двоичную запись | `sum(1 for ip in net if условие(f'{ip:b}'))` |
| Наименьший/наибольший адрес узла | `list(net.hosts())[0]` и `[-1]` |
| Параметр A «для всех адресов сети» | цикл по A, внутри `all(... for ip in net)` |

Почти всё решается одним модулем `ipaddress` и перебором маски.

## Ловушки

- «Узлы» — это `hosts()`, «адреса» — весь `net`.
- `f'{ip:b}'` даёт ровно 32 знака с ведущими нулями — удобно для подсчёта нулей.
- Если в условии таблица с буквами (A=0, B=19…) — собери ответ из букв в порядке байтов адреса.
