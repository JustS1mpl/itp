# Задание №2 — «Детектив таблицы истинности»

Нора: **ЕГЭ: код решает** · балл: 1 · на экзамене: 3–5 минут.
Что нужно из курса: `for`, `and/or/not`, `itertools.product`, `permutations`.

## Суть

Дана логическая функция F от четырёх переменных `w, x, y, z` и обрывок её таблицы истинности: три строки, часть клеток пустая, а над столбцами нет подписей. Надо понять, какой столбец — какая переменная. Ответ — четыре буквы подряд, например `yxzw`.

## Как это звучит в КИМ

«Миша заполнял таблицу истинности функции F = …, но успел заполнить лишь фрагмент из трёх различных её строк, даже не указав, какому столбцу соответствует каждая переменная. Определите, какому столбцу соответствует каждая из переменных w, x, y, z».

## Теория в двух абзацах

Логика в Python: `and`, `or`, `not`. Двух операций нет, но они легко собираются:

| В задаче | Смысл | В Python |
|---|---|---|
| a → b (импликация) | «если a, то b»; ложна только при a=1, b=0 | `not a or b` или `a <= b` |
| a ≡ b (равносильность) | истина, если a и b равны | `a == b` |
| ¬a | отрицание | `not a` |

`a <= b` работает, потому что `True` — это 1, а `False` — 0: «0 ≤ 1» истинно, «1 ≤ 0» ложно — ровно таблица импликации. Скобки ставь щедро: `==` и `<=` в Python связывают сильнее, чем `and`/`or`.

## Решение 1. Полу-ручное: код печатает таблицу, глаза ищут

1. Код выводит все строки, где F равна значению из фрагмента (обычно все строки фрагмента с одним F — например, все нули).
2. Ты сравниваешь эти строки с фрагментом: столбец, где во фрагменте три единицы, может быть только той переменной, у которой в подходящих строках тоже часто 1, и так далее.

```python
print('w x y z')
for w in range(2):
    for x in range(2):
        for y in range(2):
            for z in range(2):
                F = ((x == (not y)) <= (not (w <= x))) or (not z)
                if not F:                    # во фрагменте F = 0
                    print(w, x, y, z)
```

Строк выводится немного (часто 3–6), сопоставить их с фрагментом — минута.

## Решение 2. Полностью кодом: перебор пустых клеток и порядков

Пустые клетки — тоже переменные: перебираем их 0/1 через `product`. Порядок столбцов — перестановка букв `'wxyz'` через `permutations`. Подходит порядок, при котором все строки фрагмента дают нужное F, а сами строки различны.

```python
from itertools import product, permutations

def F(w, x, y, z):
    return ((x == (not y)) <= (not (w <= x))) or (not z)

# фрагмент из демоверсии 2027: F = 0 во всех строках, пустые клетки — a..e
for a, b, c, d, e in product([0, 1], repeat=5):
    rows = [(a, 0, 1, 0), (0, b, c, 0), (d, 1, 1, e)]
    if len(set(rows)) < 3:                 # строки должны быть разными
        continue
    for p in permutations('wxyz'):         # p[0] — буква первого столбца и т. д.
        if all(F(**dict(zip(p, r))) == 0 for r in rows):
            print(''.join(p))
```

`dict(zip(p, r))` превращает строку таблицы в словарь вида `{'y': 0, 'x': 1, ...}`, а `**` раздаёт его в функцию по именам. Ответ демоверсии — `yxzw`; код может напечатать его несколько раз (для разных заполнений пустых клеток) — это нормально.

## Вариации

| Подтип | Как узнать | Что меняется |
|---|---|---|
| Все F во фрагменте одинаковые | столбец F из одних 0 или 1 | проверка `F(...) == 0` для всех строк |
| Разные F во фрагменте | в столбце F и 0, и 1 | храни строки вместе с F: `(a, 0, 1, 0, 1)` и сравнивай `F(...) == r[-1]` |
| Строки могут повторяться | в условии нет слова «различные» | убери проверку `len(set(rows))` |
| Две функции или «F ложна ровно в…» | в тексте F и G или условие на всю таблицу | считай таблицу целиком и сравнивай количество строк |

Шаблон один: пустые клетки — переменные `product`, порядок столбцов — `permutations`.

## Ловушки

- Если в фрагменте разные F, проверяй каждую строку со своим F: храни строки как `(…, F)`.
- Не забудь про `len(set(rows))`: строки в условии «различные».
- Пропущенная скобка вокруг `==` — самая частая ошибка: `not y == x` читается как `not (y == x)`.
