# Задание №24 — «Охота за подстрокой»

Нора: **ЕГЭ: код решает** · балл: 1 · на экзамене: 10–20 минут.
Что нужно из курса: строки, срезы, `split`, `re` (по желанию), два указателя.

## Суть

Файл — одна огромная строка (до миллиона символов). Найти самую длинную подстроку с условием: «только из букв X, Y, Z», «нет двух одинаковых соседей», «содержит ровно 80 букв Y и не менее 90 подстрок 2025», «является корректным арифметическим выражением».

## Теория: два основных приёма

**1. Разрезать по «плохому».** Если в подстроке не должно быть каких-то символов, разрежь строку по ним и возьми самый длинный кусок:

```python
s = open('24.txt').readline().strip()
for ch in 'ABC':                          # всё, что не X, Y, Z, превращаем в пробел
    s = s.replace(ch, ' ')
print(max(len(part) for part in s.split()))
```

**2. Скользящее окно (два указателя).** Правая граница `r` идёт вперёд, левая `l` подтягивается, когда окно нарушает условие «не больше». Окно `s[l:r+1]` всегда «почти правильное», и за один проход мы смотрим все важные варианты. Работает за O(n) — для миллиона символов это доли секунды, тогда как перебор всех пар `(l, r)` не досчитается никогда.

## Решение 1. Полу-ручное

Для «нет двух одинаковых соседних символов» хватит цикла со счётчиком: если `s[i] != s[i-1]`, `cur += 1`, иначе `cur = 1`; ответ — максимум `cur`. Сложное условие «ровно 80 Y» можно свести к простому: позиции всех Y записать в список, тогда окно с ровно 80 буквами Y — это отрезок между Y номер `i−1` и Y номер `i+80` (не включая их). Длину каждого такого отрезка код считает сразу, а «не менее 90 подстрок 2025» проверяешь `s.count('2025', ...)` на кандидате.

## Решение 2. Полностью кодом: окно

Демоверсия 2026: максимальная длина подстроки, где `2025` встречается не менее 90 раз и ровно 80 букв `Y`.

```python
s = open('24.txt').readline().strip()
l = y = k = best = 0
for r in range(len(s)):
    if s[r] == 'Y':
        y += 1
    if s[r-3:r+1] == '2025':      # здесь закончилась ещё одна «2025»
        k += 1
    while y > 80:                 # лишняя Y — сдвигаем левый край
        if s[l] == 'Y':
            y -= 1
        if s[l:l+4] == '2025':    # ушло начало «2025»
            k -= 1
        l += 1
    if y == 80 and k >= 90:
        best = max(best, r - l + 1)
print(best)                       # 2981
```

`s[r-3:r+1]` при `r < 3` даёт пустую строку или «обрывок» — не страшно, с `'2025'` не совпадёт.

### Регулярки — для «выражений»

«Самое длинное корректное выражение из чисел без ведущих нулей и знаков +, *»: шаблон `(0|[1-9][0-9]*)([+*](0|[1-9][0-9]*))*`, а `re.finditer` найдёт кандидатов. Но жадность регулярок коварна — проверяй ответ на маленьком примере из условия.

## Вариации

| Подтип | Приём |
|---|---|
| Только разрешённые символы | разрезать по «плохим» и взять самый длинный кусок |
| Соседние символы различны / не стоят рядом | один проход со счётчиком текущей длины |
| Не содержит подстроку XYZ | длина между вхождениями XYZ (с захватом двух символов с краёв) |
| Цепочка по шаблону (DBACDBAC…) | проход со сравнением `s[i] == шаблон[текущая_длина % len(шаблон)]` |
| Ровно / не более k символов или подстрок | скользящее окно |
| Числа или выражения в строке | регулярки `re.finditer` + проверка на примере |
| Частоты символов | `collections.Counter` |
| Много строк в файле | тот же приём для каждой строки, потом выбор по условию |

## Ловушки

- `readline()` оставляет `\n` в конце — добавляй `.strip()`.
- «Подстрока» — подряд идущие символы, «подпоследовательность» — нет. В №24 всегда подряд.
- Окно должно быть максимальным: обновляй ответ на каждом шаге, а не только в конце.
