# Задание №1 — «Карта без подписей»

Нора: **ЕГЭ: почти без кода** · балл: 1 · на экзамене: 2–4 минуты.
Что нужно из курса: множества, `permutations` (для кодового способа).

## Суть

Есть схема дорог — граф с буквами A, B, C… — и таблица расстояний с номерами 1, 2, 3… Нумерация в таблице не связана с буквами. Нужно понять, какой номер — какая буква, и найти длину дороги или сумму длин.

## Теория

**Степень вершины** — сколько дорог из неё выходит. На графе считаешь линии у буквы, в таблице — заполненные клетки в строке. Вершины с уникальной степенью опознаются сразу, остальные — по соседям: «у Б степень 3, и она соседка единственной вершины степени 4».

## Решение 1. Ручное (основной способ)

1. Выпиши степени букв по графу: A — 2, B — 3, …
2. Выпиши степени номеров по таблице: П1 — 3, П2 — 2, …
3. Совпади уникальные. Для остальных смотри, с кем соединены.
4. Найди нужную клетку таблицы.

Типичная скорость — 2 минуты. Ошибка обычно одна: перепутаны две симметричные вершины. Но в симметричных случаях и ответ одинаковый, так задачу составляют.

## Решение 2. Кодом: перебор всех расстановок

Записываем рёбра графа буквами, рёбра таблицы — номерами, и перебираем все соответствия «номер → буква». Подходит то, при котором рёбра совпали.

```python
from itertools import permutations

graph = {frozenset(e) for e in 'CB CF FD DB DE BE FA AE'.split()}   # с рисунка
table = '12 15 16 23 34 35 45 46'.split()                          # заполненные клетки таблицы

print('1 2 3 4 5 6')
for p in permutations('ABCDEF'):               # p[0] — буква пункта 1 и т. д.
    if {frozenset(p[int(a) - 1] + p[int(b) - 1]) for a, b in table} == graph:
        print(*p)
```

Код печатает расстановки; длины дорог он не знает — их ты берёшь из таблицы по найденным номерам. Для демоверсии 2027: E = 3, A = 2 → 21; B = 4, C = 6 → 5; ответ 21 + 5 = **26**. Восемь букв — 40 320 перестановок, это мгновенно.

## Вариации

Почти всегда спрашивают длину одной дороги или сумму двух. Реже — **кратчайший путь** между пунктами: сначала опознаёшь вершины, как обычно, потом смотришь в таблицу и перебираешь пути через одного-двух соседей. Если вершин много, путь можно найти тем же перебором с `permutations` или функцией кратчайшего пути из главы №23.

## Ловушки

- `frozenset` нужен, потому что дорога AB и дорога BA — одна и та же.
- Таблица симметрична: клетку (2, 3) и (3, 2) не считай дважды — выписывай пары с меньшим номером первым.
- «Длина пути из A в C через B» — сумма двух дорог, а не одна клетка.
