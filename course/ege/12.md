Нора: **ЕГЭ: исполнители и графы** · балл: 1 · на экзамене: 5–10 минут.
Что нужно из курса: словари, строки, `while`.
С 2026 года на месте «Редактора» — **машина Тьюринга** (МТ).

## Суть

МТ — головка над бесконечной лентой с символами. Программа — таблица: строка — состояние (q0, q1…), столбец — символ под головкой, в клетке — команда «что записать, куда сдвинуться, в какое состояние перейти». Нужно понять, что останется на ленте, или подобрать исходные данные.

Команда `1, L, q2`: записать `1`, сдвинуться влево, перейти в q2. `S` — остановиться после записи, `N` — остаться на месте.

## Теория: МТ на Python — 15 строк

```python
def run(tape, pos, prog, state='q0', limit=10**6):
    tape = dict(enumerate(tape))           # клетка -> символ, пустые — 'λ'
    for _ in range(limit):
        sym = tape.get(pos, 'λ')
        write, move, state = prog[state][sym]
        tape[pos] = write
        if move == 'S':
            break
        pos += {'L': -1, 'R': 1, 'N': 0}[move]
    cells = sorted(k for k, v in tape.items() if v != 'λ')
    return ''.join(tape[k] for k in range(cells[0], cells[-1] + 1)) if cells else ''
```

Программа — словарь словарей: `prog['q1']['0'] = ('0', 'L', 'q1')`.

## Решение 1. Полу-ручное: понять, что делает программа

Демоверсия 2027: на ленте `2025` в двоичной записи (`11111101001`), головка справа.

| | λ | 0 | 1 |
|---|---|---|---|
| q0 | λ, L, q1 | | |
| q1 | 1, L, q2 | 0, L, q1 | 1, L, q1 |
| q2 | λ, S, q2 | | |

q0 шагает на последнюю цифру; q1 идёт влево, ничего не меняя; на пустой клетке слева пишет `1`. Итог — `1` перед записью числа: 2025 + 2¹¹ = 2025 + 2048 = **4073**.

Второй частый вид: «после работы осталось 343 нуля — сколько нулей могло быть максимум?» Здесь программа от правого края меняет нули на единицы до первой единицы, а её делает нулём. Код не нужен — нужна мысль: если исходно 999 нулей и одна единица, то после работы нулей 342 + 1 = 343. Ответ **999**.

## Решение 2. Полностью кодом: симуляция

```python
prog = {
    'q0': {'λ': ('λ', 'L', 'q1')},
    'q1': {'λ': ('1', 'L', 'q2'), '0': ('0', 'L', 'q1'), '1': ('1', 'L', 'q1')},
    'q2': {'λ': ('λ', 'S', 'q2')},
}
s = bin(2025)[2:]
res = run(s, len(s), prog)              # головка — сразу справа от записи
print(int(res, 2))                      # 4073
```

Если вопрос «при каком исходном числе…», оберни симуляцию в цикл по всем кандидатам — МТ на ленте из 10–20 клеток работает мгновенно.

## Вариации

| Подтип | Что делать |
|---|---|
| Результат работы программы | симулируй |
| Восстановить исходное число («наибольшее/наименьшее исходное») | перебери кандидатов, симулируй каждого, сравни с результатом |
| Сколько нулей/единиц стало или было | пойми, что делает программа (обычно: «идёт до края и меняет…»), и посчитай в уме; код — для проверки |
| Лента с буквами, а не цифрами | тот же симулятор, другой алфавит |

## Ловушки

- Пустой символ λ пишут по-разному (λ, пробел, a0) — используй тот же, что в таблице.
- Пустая клетка таблицы = такая ситуация невозможна. Если твоя симуляция туда попала (`KeyError`), ты неверно задал старт.
- Номер «ближайшей справа клетки» — `len(s)`, если запись занимает клетки `0…len(s)-1`.
