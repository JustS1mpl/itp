# Задание №5 — «Фабрика двоичных чисел»

Нора: **ЕГЭ: код решает** · балл: 1 · на экзамене: 3–4 минуты.
Что нужно из курса: `bin`, `int(s, 2)`, срезы строк, `for`.

## Суть

Алгоритм берёт число N, переводит в двоичную запись, что-то к ней дописывает или меняет и получает новое число R. Спрашивают: какое наименьшее R больше заданного, или наименьшее N, при котором R больше порога, и т. п.

## Как это звучит в КИМ

«1. Строится двоичная запись числа N. 2. Если N чётное, к записи справа и слева дописывается по две единицы; иначе справа дописываются два нуля, а слева — единица. Укажите наименьшее число R, превышающее 95, которое может быть результатом работы алгоритма».

## Теория

- `bin(13)` → `'0b1101'`; без префикса — `bin(13)[2:]` или `f'{13:b}'`.
- Обратно: `int('1101', 2)` → `13`.
- «Сумма цифр двоичной записи» = количество единиц: `s.count('1')`.
- Для троичной системы `bin` нет — пиши функцию перевода (см. задание 14).

## Решение 1. Полу-ручное

Прогони алгоритм на примере из условия в голове или коде, чтобы понять правило. Потом прикинь размер: R больше 95 — это 7 двоичных разрядов (`1100000`). Запись R длиннее записи N на 3–4 разряда, значит N — трёх-четырёхзначное в двоичной. Дальше пара проверок руками или короткий цикл по маленьким N:

```python
for n in range(1, 30):
    s = bin(n)[2:]
    s = '11' + s + '11' if n % 2 == 0 else '1' + s + '00'
    print(n, int(s, 2))
```

Глазами ищешь в столбце первое число больше 95.

## Решение 2. Полностью кодом

Строим R для всех N с запасом и берём минимум из подходящих. Минимум, а не первое найденное: R не обязательно растёт вместе с N.

```python
def R(n):
    s = bin(n)[2:]
    if n % 2 == 0:
        s = '11' + s + '11'
    else:
        s = '1' + s + '00'
    return int(s, 2)

print(R(13), R(6))                       # проверка по условию: 116 123
print(min(R(n) for n in range(1, 10000) if R(n) > 95))
```

Ответ демоверсии 2027 — `100`.

## Частые варианты правила

- «Дописать бит чётности» (0, если единиц чётно, иначе 1): `s += str(s.count('1') % 2)`.
- «Заменить два левых разряда на 10»: `s = '10' + s[2:]`.
- «Если N кратно 3, дописать в конец три последние цифры»: `s += s[-3:]`.

## Вариации

Меняются две вещи: **правило** построения R и **вопрос**.

Правила: дописать биты чётности, дописать остаток от деления на 3 в двоичном виде, заменить старшие разряды, инвертировать биты, работать с **троичной** или десятичной записью. Для троичной `bin` нет — пиши перевод сам:

```python
def tern(n):
    s = ''
    while n:
        s = str(n % 3) + s
        n //= 3
    return s or '0'
```

Вопросы:

| Спрашивают | Код |
|---|---|
| наименьшее R больше X | `min(R(n) for n in rng if R(n) > X)` |
| наименьшее N, при котором R > X | `min(n for n in rng if R(n) > X)` |
| наибольшее N, при котором R ≤ X | `max(n for n in rng if R(n) <= X)` |
| N, при котором R наибольшее среди меньших X | сначала `best = max(R(n) ... if R(n) < X)`, потом `min(n ... if R(n) == best)` |
| сколько разных R / сумма разных R | `len({...})` или `sum({...})` — множество убирает повторы |

## Ловушки

- Читай, что спрашивают: R или N, «больше» или «не меньше».
- Диапазон перебора бери с запасом (до 10 000 и больше) — это бесплатно.
- В правиле «сумма цифр» речь о цифрах двоичной записи, а не десятичного N.
