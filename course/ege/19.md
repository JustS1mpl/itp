# Задание №19 — «Две кучи камней: первый ход»

Нора: **ЕГЭ: почти без кода** · балл: 1 · на экзамене: 5–10 минут (вместе с 20 и 21 — около 20).
Что нужно из курса: функции, рекурсия, `lru_cache`.
Задания 19, 20 и 21 — три вопроса к одной игре. Код пишется один раз.

## Суть

Двое по очереди меняют кучи камней (добавить 4 камня в одну кучу, удвоить кучу…). Выигрывает тот, кто первым доведёт сумму до порога (133 и больше). Вопрос 19 обычно такой: «Известно, что Ваня выиграл своим первым ходом после неудачного первого хода Пети. Найдите минимальное S».

## Теория: выигрышные и проигрышные позиции

Позиция — пара куч (a, b). Говорим, что позиция **выигрышная**, если игрок, который сейчас ходит, может выиграть при любой игре соперника.

- Если одним ходом можно дойти до порога — выигрыш в 1 ход.
- Позиция проигрышная, если **все** ходы ведут в выигрышные позиции соперника.
- Позиция выигрышная в k ходов, если **есть** ход в позицию, проигрышную для соперника.

Задание 19 — особый случай: Петя ходит **неудачно** (не обязательно лучшим ходом), и после этого Ваня выигрывает сразу. Значит, нужна позиция, из которой **хотя бы один** ход Пети даёт Ване выигрыш в один ход, а сам Петя за ход выиграть не может.

## Решение 1. Полу-ручное: рассуждение

Демоверсия 2027: кучи (17, S), ходы «+4» или «×2» в любую кучу, порог 133.

Ваня выигрывает первым ходом, если после хода Пети сумма такая, что одно удвоение большей кучи дотягивает до 133. Самый «длинный» прыжок — удвоить большую кучу. Петя «помогает», тоже удваивая S: (17, 2S). Ваня удваивает ещё раз: 17 + 4S ≥ 133 → S ≥ 29. При S = 29 Петя сам выиграть не может (17 + 58 = 75 < 133). Ответ **29**.

## Решение 2. Полностью кодом: одна функция на все три задания

```python
from functools import lru_cache

LIMIT = 133

def moves(a, b):
    return [(a + 4, b), (a * 2, b), (a, b + 4), (a, b * 2)]

@lru_cache(None)
def game(a, b):
    """'W1', 'L1', 'W2', 'L2'… — кто выигрывает и за сколько ходов; None — дольше."""
    if a + b >= LIMIT:
        return 'END'
    res = [game(*m) for m in moves(a, b)]
    if 'END' in res:
        return 'W1'
    if all(r == 'W1' for r in res):
        return 'L1'
    if 'L1' in res:
        return 'W2'
    if all(r in ('W1', 'W2') for r in res):
        return 'L2'
    return None

# 19: после неудачного хода Пети Ваня выигрывает первым ходом —
# у Пети есть ход в позицию W1 для Вани, но сам Петя за ход не выигрывает
print([s for s in range(1, 116)
       if game(17, s) != 'W1' and any(game(*m) == 'W1' for m in moves(17, s))][0])   # 29
```

Строки `W1/L1/W2/L2` читаются так: «ходящий выиграет первым ходом», «ходящий проиграет, соперник выиграет первым ходом», и т. д. Задания 20 и 21 используют ту же функцию.

## Вариации

| Подтип | Что поменять в `moves` и `game` |
|---|---|
| Две кучи, рост до порога | базовая версия |
| Одна куча | позиция — одно число, `moves(n)` |
| Ходы уменьшают кучу, проигрывает взявший последний / ход до нуля | порог становится «нижним»: `if n <= 0` или «нельзя сделать ход» |
| Особые правила хода («нельзя повторять ход соперника», «удвоить только меньшую кучу») | правило — в `moves`; иногда в позицию добавляется последний ход |

Логика W1/L1/W2/L2 не меняется никогда — меняются только ходы и условие конца игры.

## Ловушки

- В 19-м Петя ходит **как угодно**, поэтому `any`, а не «лучший ход».
- Один ход можно сделать в любую кучу — не забудь все варианты в `moves`.
- Если ходы «добавить 1 или 2», а порог большой — рекурсия глубокая, ставь `sys.setrecursionlimit(10**4)`.
