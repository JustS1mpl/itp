## Суть

Анализ данных: точки (звёзды, частицы) нужно разбить на **кластеры** — кучки близких точек, найти у каждого кластера **центр** и ответить на вопрос про центры или расстояния. С 2027 года кластеризуют не по координатам, а по числовой характеристике (кинетической энергии частиц): «модуль разности энергий любых двух частиц кластера не больше R».

## Теория

- Числа в файле с запятой: `line.replace(',', '.').split()`.
- Кинетическая энергия: E = m·(Vx² + Vy²) / 2.
- **Центр кластера** — его частица, у которой сумма |Eᵢ − Eⱼ| до остальных минимальна (для координат — сумма расстояний). Ищем перебором: O(n²) на кластер — нормально для тысяч точек.
- Кластеры по одному числу ищутся сортировкой: если отсортировать энергии, кластеры — это куски между самыми большими «разрывами». При K = 4 режем по трём наибольшим разрывам.

## Решение 1. Полу-ручное: посмотреть и провести границы

Посчитай энергии, отсортируй и посмотри глазами (или построй гистограмму в Excel): значения собираются в 4 плотные кучки, между ними пустоты. Границы записываешь руками — например, `E < 4`, `4 ≤ E < 6`, `6 ≤ E < 9`, `E ≥ 9` — и раскладываешь частицы по этим условиям. Дальше центры и расстояния считает код. На экзамене так быстрее всего, но границы обязательно проверь: напечатай `min` и `max` энергии в каждой кучке.

## Решение 2. Полностью кодом

```python
from math import dist

pts = []
for line in open('27.txt'):
    x, y, vx, vy, m, kind = line.replace(',', '.').split()
    x, y, vx, vy, m = map(float, (x, y, vx, vy, m))
    pts.append((m * (vx**2 + vy**2) / 2, x, y, kind))
pts.sort()

# режем по трём самым большим разрывам между соседними энергиями
gaps = sorted(range(1, len(pts)), key=lambda i: pts[i][0] - pts[i-1][0])[-3:]
cuts = [0] + sorted(gaps) + [len(pts)]
clusters = [pts[a:b] for a, b in zip(cuts, cuts[1:])]

def center(cl):
    return min(cl, key=lambda p: sum(abs(p[0] - q[0]) for q in cl))

q1 = 0
for cl in clusters:
    two = [p for p in cl if p[3] == 'II']
    for p in two:
        for q in two:
            q1 = max(q1, dist(p[1:3], q[1:3]))
q2 = max(center(cl)[0] for cl in clusters)
print(int(q1 * 10000), int(q2 * 10000))      # 539936 100704
```

Проверка на примере из условия: частица `0,67 –2,14 3,0 –4,0 0,2 V` даёт E = 0,2·25/2 = 2,5.

## Вариации

| Подтип | Что меняется |
|---|---|
| Кластеры по одному числу (энергия) | сортировка, разрез по большим разрывам |
| Кластеры по координатам (звёзды, геопозиции) | точки близки на плоскости: раздели по координатам (часто видно по графику — «кучки» отделяются прямыми `x < 2`, `y > 5`) или собери кучки обходом соседей ближе R |
| Центр по сумме расстояний | `min(cl, key=lambda p: sum(dist(p, q) for q in cl))` |
| Файлы А и Б | два файла, разное число кластеров; в ответе две строки |
| Аномалии (точки не из кластеров) | отбрасываются условием из текста |

Собрать кучки «обходом соседей» (если две точки ближе R, они в одном кластере):

```python
def clusters(pts, R):
    left, res = list(pts), []
    while left:
        cl = [left.pop()]
        for p in cl:                       # список растёт во время обхода
            near = [q for q in left if dist(p, q) <= R]
            for q in near:
                left.remove(q)
            cl += near
        res.append(cl)
    return res
```

## Ловушки

- В примере из условия бывает «длинное тире» `–` вместо минуса: `replace('–', '-')`.
- Файлы А (маленький) и Б (большой) бывают разными по числу кластеров — проверяй K для каждого.
- Центр по сумме модулей — это **медиана** кластера; но если требуют «минимальную сумму расстояний по координатам», считай честно перебором.
