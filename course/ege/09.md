Что нужно из курса: чтение файла, `split`, `sorted`, `set`, `count`.

## Суть

Электронная таблица: в каждой строке 5–7 чисел. Посчитать строки, где выполнены условия вроде «все числа различны» и «удвоенная сумма максимального и минимального больше суммы остальных», «есть ровно одно повторяющееся число», «среднее неповторяющихся меньше повторяющегося».

## Теория: условия на одну строку

| Условие | Python |
|---|---|
| все числа различны | `len(set(r)) == len(r)` |
| ровно одно число повторяется дважды | `len(set(r)) == len(r) - 1` |
| число встречается трижды | `any(r.count(x) == 3 for x in r)` |
| максимум, минимум | `max(r)`, `min(r)` |
| «остальные» после max и min | `s = sorted(r)`, тогда `s[1:-1]` |
| сумма неповторяющихся | `sum(x for x in r if r.count(x) == 1)` |

## Решение 1. Полу-ручное: формулы в Excel/Calc

Рядом с данными (A:E) добавь столбцы:
- F: `=ЕСЛИ(МАКС(СЧЁТЕСЛИ(A1:E1;A1:E1))=1;1;0)` — все различны (формула массива; в новых версиях работает сразу).
- G: `=2*(МАКС(A1:E1)+МИН(A1:E1))>СУММ(A1:E1)-МАКС(A1:E1)-МИН(A1:E1)`.
- H: `=И(F1=1;G1)`, протянуть, `=СЧЁТЕСЛИ(H:H;ИСТИНА)`.

Это задание придумано для Excel, и формулы короткие. Но условия вроде «повторяется ровно одно число ровно два раза» в формулах становятся длинными — там проще кодом.

## Решение 2. Полностью кодом

Сохрани таблицу как `9.txt` (числа через табуляцию) или `9.csv`.

```python
k = 0
for line in open('9.txt'):
    r = list(map(int, line.split()))
    s = sorted(r)
    if len(set(r)) == len(r) and 2 * (s[0] + s[-1]) > sum(s[1:-1]):
        k += 1
print(k)                     # демоверсия 2027: 4874
```

`line.split()` без аргумента режет и по табуляциям, и по пробелам. Для CSV с `;` — `line.split(';')`.

## Вариации

Условия меняются, приём один: строку превращаешь в список чисел и проверяешь условия через `set`, `sorted`, `count`.

| Подтип | Подсказка |
|---|---|
| Все различны / есть повтор | `len(set(r))` |
| Ровно одно число повторяется дважды | `[r.count(x) for x in set(r)]` должен быть `[2, 1, 1, ...]` |
| Среднее неповторяющихся | `u = [x for x in r if r.count(x) == 1]; sum(u) / len(u)` |
| Произведения, квадраты, треугольники | `s = sorted(r)`, работай с `s[0]`, `s[-1]` и серединой |
| Ответ — не количество, а номер строки или сумма в ней | `enumerate(open(...), 1)`, запоминай номер последней подходящей |

## Ловушки

- «Числа различны» — проверка на всю строку, а не на соседей.
- «Остальные три числа» — без одного максимума и одного минимума, даже если таких чисел несколько. `sorted` и срез `[1:-1]` делают ровно это.
- В строке может оказаться пустая последняя строка файла — `if not line.strip(): continue`.
