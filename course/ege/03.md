## Суть

Файл — маленькая реляционная база данных: три листа. «Движение товаров» (дата, магазин, артикул, сколько упаковок, поступление или продажа), «Товар» (артикул, название, вес/объём упаковки, цена), «Магазин» (ID, район, адрес). Вопрос: сколько килограммов зефира получили магазины на Прибрежной улице с 5 по 19 июня.

## Теория

Таблицы связаны **ключами**: в «Движении» стоит не название товара, а артикул; не адрес, а ID магазина. Чтобы отфильтровать по названию и улице, надо «подтянуть» данные из двух других листов — в Excel это `ВПР` (VLOOKUP), в Python — словарь «ключ → строка».

## Решение 1. Полу-ручное: фильтры Excel/Calc

1. На листе «Движение» добавь столбцы «Товар», «Адрес», «Вес упаковки»: `=ВПР(D2;Товар!A:F;3;0)`, `=ВПР(C2;Магазин!A:C;3;0)`, `=ВПР(D2;Товар!A:F;5;0)`.
2. Включи автофильтр: тип операции — «Поступление», товар — содержит «Зефир», адрес — содержит «Прибрежная», дата — между 05.06 и 19.06.
3. Добавь столбец «упаковок × вес», выдели видимые ячейки — сумма внизу окна. Граммы переведи в кг.

Ответ демоверсии 2027 — **1630**.

## Решение 2. Полностью кодом

Сохрани каждый лист как CSV с разделителем `;` (Файл → Сохранить как).

```python
def rows(name):
    lines = open(name, encoding='utf-8').read().splitlines()
    return [line.split(';') for line in lines[1:]]       # без заголовка

goods = {r[0]: r for r in rows('goods.csv')}         # артикул -> строка
shops = {r[0]: r for r in rows('shops.csv')}         # ID магазина -> строка

total = 0
for op_id, date, shop, art, qty, kind in rows('moves.csv'):
    d, m, y = map(int, date.split('.'))
    g, s = goods[art], shops[shop]
    if (kind == 'Поступление' and 'Зефир' in g[2] and 'Прибрежная' in s[2]
            and m == 6 and 5 <= d <= 19):
        total += int(qty) * float(g[4])                # упаковки × граммов в упаковке
print(total / 1000)                                    # 1630.0
```

## Вариации

Меняется только то, **что суммировать**: выручку (упаковки × цена), массу (упаковки × вес), объём (упаковки × объём), количество упаковок или разницу «поступило − продано». Фильтры те же: тип операции, товар, район или улица, даты. В коде меняется одна строка с `total +=`. Иногда спрашивают процент или «на сколько больше» — посчитай две суммы и вычти.

## Ловушки

- Выручка = упаковки × цена, масса = упаковки × вес упаковки. Не путай столбцы.
- «Поступило» — тип операции «Поступление», «продано» — «Продажа».
- Единицы: граммы → кг, миллилитры → литры.
- Границы дат включительно.
