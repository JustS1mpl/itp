# Задание №16 — «Функция зовёт сама себя»

Нора: **ЕГЭ: код решает** · балл: 1 · на экзамене: 2–5 минут.
Что нужно из курса: функции, рекурсия, `sys.setrecursionlimit`, `functools.lru_cache`.

## Суть

Функция задана рекуррентно: F(n) = 1 при n = 1, F(n) = n · F(n−1) при n > 1. Надо посчитать выражение вроде (F(3038) + 5·F(3037)) / F(3036). Перенос формулы в код — минута; ловушки — глубина рекурсии и огромные числа.

## Теория

- Python по умолчанию не даёт рекурсии глубже ~1000. Поднять: `sys.setrecursionlimit(10**6)`.
- Повторные вызовы с одним n — кэшируй: `@lru_cache(None)` — иначе программа с двумя ветвями (F(n−1) + F(n−2)) будет считать вечно.
- Деление огромных чисел через `/` превращает их во `float` и падает с переполнением. Используй `//`, когда знаешь, что делится нацело.

## Решение 1. Полу-ручное: сократить выражение

F(n) = n! (факториал). Тогда
(F(3038) + 5·F(3037)) / F(3036) = (3038·3037·3036! + 5·3037·3036!) / 3036! = 3037·(3038 + 5) = 3037·3043 = **9241591**.

Умножение проверяешь кодом в одну строку: `print(3037 * 3043)`.

Такие «сокращения» работают, когда F(n) — произведение или сумма с простой закономерностью. Например, F(n) = n + F(n−1) при n ≥ 11 и F(n) = n при n < 11: тогда F(2024) − F(2021) = 2024 + 2023 + 2022 = 6069.

## Решение 2. Полностью кодом

```python
import sys
sys.setrecursionlimit(10**6)

def F(n):
    if n == 1:
        return 1
    return n * F(n - 1)

print((F(3038) + 5 * F(3037)) // F(3036))      # 9241591
```

Здесь у функции одна ветка (F зовёт себя один раз), кэш не нужен. А вот с `@lru_cache` такая глубокая рекурсия в Python 3.12+ упадёт с `RecursionError` даже после `setrecursionlimit`: у кэша свой предел вложенности. Выход — «прогреть» кэш снизу вверх, тогда каждый вызов спускается на одну ступеньку:

```python
from functools import lru_cache

@lru_cache(None)
def G(n):
    if n == 1:
        return 1
    return n * G(n - 1)

for i in range(1, 3039):       # прогрев: G(1), G(2), … — каждый раз глубина 1
    G(i)
print((G(3038) + 5 * G(3037)) // G(3036))      # 9241591
```

Второй типичный вид — «сколько чисел n из отрезка, для которых F(n) …» или «чему равно F(…) при сложной системе условий». Пишешь функцию строго по условию, ветки в том же порядке.

```python
@lru_cache(None)
def F(n):
    if n < 3:
        return n
    if n % 2 == 0:
        return F(n // 2) + 1
    return F(n - 1) * 2
print(sum(1 for n in range(1, 1001) if F(n) == 10))
```

## Вариации

| Подтип | Приём |
|---|---|
| Вычислить F(n) или выражение | функция по условию, при необходимости `setrecursionlimit` |
| Огромные n с делением | сокращай вручную или считай `//` |
| Две функции F и G, вызывающие друг друга | две функции, `lru_cache` на обе |
| «Для какого n F(n) = 25» / «сколько n с F(n) = 3» | цикл по n; если n до 10⁹ — ищи закономерность на маленьких n |
| Условия с остатками (`n % 3 == 1`) | переписывай ветки в том же порядке |

## Ловушки

- `/` вместо `//` на больших числах → `OverflowError` или неточный ответ.
- Ветки условия «n > 1» и «n ≥ 11» переписывай дословно, не «улучшай».
- Без `lru_cache` двойная рекурсия F(n−1) + F(n−2) при n = 50 уже не досчитается.
