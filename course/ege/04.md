# Задание №4 — «Код, который не перепутаешь»

Нора: **ЕГЭ: почти без кода** · балл: 1 · на экзамене: 3–5 минут.
Что нужно из курса: строки, `startswith`, `product` (для кодового способа).

## Суть

Буквы кодируют двоичными словами разной длины. Код должен удовлетворять **условию Фано**: ни одно кодовое слово не является началом другого — тогда сообщение расшифровывается однозначно. Часть кодов известна; нужно подобрать остальные так, чтобы сообщение (или сумма длин) было минимальным.

## Теория: двоичное дерево

Рисуем дерево: от корня влево 0, вправо 1. Каждое кодовое слово — **лист**: ниже него ничего нет, и выше по его ветке нет других слов. Свободные ветки — кандидаты для новых букв. Чем ближе к корню свободная ветка, тем короче код.

Пример демоверсии 2027: Б — 00, Н — 010, Л — 111. Свободны ветки `011` (длина 3) и `10` (длина 2), а также всё, что ниже `110`. Нужно закодировать К и О в слове КОЛОБОК (К ×2, О ×3, Л ×1, Б ×1).

## Решение 1. Ручное (основной способ)

Самое частое — О (3 раза), ей самый короткий свободный код: `10` (2 знака). К — `011` или `110` (3 знака). Считаем: О: 3·2 = 6, К: 2·3 = 6, Л: 3, Б: 2 → 6 + 6 + 3 + 2 = **17**.

Правило: сначала найди все свободные «ветки», потом раздай короткие самым частым буквам.

## Решение 2. Кодом: перебор кодов

Перебираем коды для неизвестных букв среди всех двоичных слов длиной до 4–5 и проверяем условие Фано.

```python
from itertools import product

def fano(codes):
    for a in codes:
        for b in codes:
            if a != b and b.startswith(a):
                return False
    return True

words = [''.join(p) for k in range(1, 5) for p in product('01', repeat=k)]
known = {'Б': '00', 'Н': '010', 'Л': '111'}
msg = 'КОЛОБОК'
best = None
for k in words:
    for o in words:
        codes = {**known, 'К': k, 'О': o}
        if len(set(codes.values())) == 5 and fano(list(codes.values())):
            length = sum(len(codes[ch]) for ch in msg)
            best = length if best is None else min(best, length)
print(best)            # 17
```

Две неизвестные буквы — 30 × 30 вариантов, мгновенно. Для трёх-четырёх неизвестных перебор тоже быстрый, если ограничить длину кода 4–5 символами.

## Вариации

| Подтип | Что делать |
|---|---|
| Минимальная длина сообщения или сумма длин кодов | свободные ветки дерева → короткие коды самым частым буквам |
| Найти сам код буквы («наименьшее числовое значение», «кратчайшее кодовое слово») | перебираешь коды по возрастанию длины, потом по значению; первый подходящий по Фано — ответ |
| Троичный алфавит (0, 1, 2) | то же дерево, но у каждого узла три ветки; в коде `product('012', repeat=k)` |
| Обратное условие Фано (ни одно слово не является **концом** другого) | проверка `b.endswith(a)` вместо `startswith` |

## Ловушки

- Код не может совпадать с началом **и** не может начинаться с другого кода — проверяй в обе стороны (функция выше проверяет все пары).
- Иногда спрашивают «наименьший код для буквы X в лексикографическом порядке» — тогда ищи не длину, а сам код.
- Если просят «сумму длин всех кодовых слов», считай по одному разу на букву, а не по сообщению.
