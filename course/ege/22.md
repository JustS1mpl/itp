# Задание №22 — «Кто кого ждёт»

Нора: **ЕГЭ: исполнители и графы** · балл: 1 · на экзамене: 10–15 минут.
Что нужно из курса: словари, рекурсия или циклы, чтение таблицы.

## Суть

Есть N процессов: у каждого время выполнения и список процессов, которые должны закончиться раньше. Все стартуют как можно раньше, параллельно. Вопросы: за сколько мс выполнится всё; сколько процессов идёт одновременно на 7-й мс; сколько успеет закончиться за 17 мс.

## Теория

Время окончания процесса = его длительность + максимум окончаний процессов, от которых он зависит (или 0, если независимый):

`end[i] = time[i] + max(end[j] for j in deps[i])`

Процесс i работает в миллисекунды с `end[i] - time[i] + 1` по `end[i]` (нумерация мс с 1). Пример из условия: процесс 3 длится 2 мс и ждёт 2 и 4, которые кончаются на 7-й мс — значит, 3 идёт на 8-й и 9-й мс.

## Решение 1. Полу-ручное: формула в таблице

В Excel/Calc рядом с данными добавь столбец «конец». Для независимых процессов — длительность. Для зависимых — `=B5 + МАКС(конец процесса 1; конец процесса 4)`: ссылки на нужные строки вписываешь руками, ориентируясь по ID. Процессов в файле обычно 15–30 — это 5 минут. Общее время — `МАКС` столбца. Для «сколько идёт на 7-й мс» добавь столбец «начало» и посчитай `СЧЁТЕСЛИМН(начало;"<=7";конец;">=7")`.

## Решение 2. Полностью кодом

Таблицу копируем в `22.txt` (три столбца через табуляцию):

```python
from functools import lru_cache

time, deps = {}, {}
for line in open('22.txt'):
    pid, t, d = line.split('\t')
    time[int(pid)] = int(t)
    deps[int(pid)] = [int(x) for x in d.replace(' ', '').split(';') if x.strip() not in ('', '0')]

@lru_cache(None)
def end(i):
    return time[i] + max((end(j) for j in deps[i]), default=0)

print('всё выполнится за', max(end(i) for i in time))
ms = 7
print('идёт на', ms, 'мс:', sum(1 for i in time if end(i) - time[i] + 1 <= ms <= end(i)))
print('завершится за 17 мс:', sum(1 for i in time if end(i) <= 17))
```

Ответ демоверсии 2027 (процессов на 7-й мс) — `8`.

## Вариации

| Спрашивают | Как |
|---|---|
| Общее время | `max(end(i))` |
| Сколько процессов идёт на k-й мс | `start <= k <= end` |
| Сколько закончится за k мс | `end <= k` |
| Минимальное время, чтобы завершились k процессов | `sorted(end.values())[k - 1]` |
| ID процесса, который закончится предпоследним | сортировка по `end` |
| Минимальное время конкретного процесса | `end(id)` |
| Длительность отрезка, когда одновременно идут k процессов | пройди по всем мс от 1 до конца и посчитай, сколько процессов работает в каждую |
| Процессы можно сдвигать / ставить на паузу | это уже задача на расписание — читай условие, часто решается руками по таблице |

## Ловушки

- «Выполняются на 7-й мс» — и начатые в эту мс, и заканчивающиеся в неё.
- Разделители в столбце зависимостей бывают `;` и `; ` — убирай пробелы.
- Если в условии сказано, что процессы можно сдвигать (не самое раннее время), это другая задача — читай внимательно.
