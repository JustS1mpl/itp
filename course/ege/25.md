## Суть

Перебрать большие числа (от миллиона до 10¹⁰) и найти те, у которых особые делители или запись по **маске**. Два классических вида:
1. **Маска**: «числа, не превышающие 10¹⁰, подходящие под маску `1?2157*4` и делящиеся на 2025». `?` — ровно одна цифра, `*` — любая (в том числе пустая) последовательность цифр.
2. **Делители**: «найдите первые 5 чисел больше 1 103 285 717, которые являются произведением ровно двух простых, каждый из которых содержит `16` ровно один раз».

## Теория: делители за √n

Делители ходят парами: если d делит n, то и n // d делит. Значит, достаточно идти до √n:

```python
def divisors(n):
    res = set()
    for d in range(1, int(n**0.5) + 1):
        if n % d == 0:
            res |= {d, n // d}
    return sorted(res)

def is_prime(n):
    if n < 2: return False
    for d in range(2, int(n**0.5) + 1):
        if n % d == 0:
            return False
    return True
```

Для чисел ~10⁹ это ~30 000 шагов на число. Если нужно проверить много чисел — ищи **наименьший** делитель и сразу делай выводы.

## Решение 1. Полу-ручное: шагать по кратным

Маска `1?2157*4`, делится на 2025. Перебирать все числа до 10¹⁰ нельзя, но можно идти шагом 2025: `range(2025, 10**10, 2025)` — это ~5 млн чисел, а проверка маски — `fnmatch`:

```python
from fnmatch import fnmatch
for n in range(0, 10**10 + 1, 2025):
    if fnmatch(str(n), '1?2157*4'):
        print(n, n // 2025)
```

Работает около минуты. Быстрее — перебрать то, что спрятано под `?` и `*` (маска короткая), и проверять делимость:

```python
for q in '0123456789':
    for k in range(0, 4):                       # длина «*» так, чтобы n ≤ 10**10
        for mid in range(10**k):
            s = '1' + q + '2157' + (str(mid).zfill(k) if k else '') + '4'
            n = int(s)
            if n <= 10**10 and n % 2025 == 0:
                print(n, n // 2025)
```

(Результат потом отсортируй — порядок перебора не по возрастанию.)

## Решение 2. Полностью кодом: делители

Демоверсия 2027: произведение ровно двух простых, у обоих ровно одно вхождение `16`.

```python
def smallest_divisor(n):
    for d in range(2, int(n**0.5) + 1):
        if n % d == 0:
            return d
    return n

found = 0
n = 1103285717
while found < 5:
    n += 1
    p = smallest_divisor(n)
    if p == n:                       # простое — не произведение двух
        continue
    q = n // p
    if smallest_divisor(q) == q and str(p).count('16') == 1 and str(q).count('16') == 1:
        print(n, p)
        found += 1
```

Наименьший делитель p всегда простой; если и n // p простое — значит, у n ровно два простых множителя. Ответ начинается с `1103299319 1693`.

## Вариации

| Подтип | Приём |
|---|---|
| Маска (`?`, `*`) + делимость | шаг по кратным или перебор того, что под маской; `fnmatch` |
| Маска + «ровно три делителя» | у числа ровно 3 делителя ⇔ это квадрат простого |
| Произведение двух простых | наименьший делитель p, и `n // p` простое |
| Сумма/среднее/наибольший делитель | функция `divisors` до √n |
| «Первые 5 чисел больше N» | `while` и счётчик найденных |
| «5 наибольших чисел меньше N» | идти вниз от N |

Скорость: проверка делителей до √n для числа ~10⁹ — 30 000 шагов. Миллион таких чисел — уже слишком долго, поэтому ищи, как сократить перебор.

## Ловушки

- `range(1, n)` для поиска делителей числа 10⁹ — это навсегда. Только до √n.
- `*` в маске может быть пустым — не забудь k = 0.
- «Делители, отличные от 1 и самого числа» — убери их из множества.
