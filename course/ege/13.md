# Задание №13 — «Сколько дорог к числу»

Нора: **ЕГЭ: исполнители и графы** · балл: 1 · на экзамене: 4–8 минут.
Что нужно из курса: функции, рекурсия, `lru_cache`.
До 2025 года это было задание №23.

## Суть

Исполнитель меняет число командами («прибавь 1», «умножь на 2», «поменяй местами две цифры»). Сколько существует программ, переводящих число a в число b? С дополнениями: «траектория содержит 10», «не содержит 17», «первая команда — B».

## Теория: считать от конца не нужно — нужна функция

Пусть `f(x, y)` — число программ из x в y. Первая команда либо A, либо B — поэтому

`f(x, y) = f(x + 1, y) + f(B(x), y)`, а базы: `f(y, y) = 1` (пустая программа), `f(x, y) = 0`, если x уже «проскочил» y.

Траектория «проходит через 10» — разбиваем путь: `f(a, 10) * f(10, b)`. «Не содержит 17» — в функции возвращаем 0, если `x == 17`.

## Решение 1. Полу-ручное: табличка

Классический ручной способ — выписать числа от a до b и для каждого посчитать количество путей как сумму путей из чисел, откуда в него можно попасть. Для «прибавь 1 / умножь на 2» от 1 до 20 это 20 клеток — 5 минут на бумаге. Код ниже делает то же самое, только сам.

```python
n = {1: 1}
for x in range(2, 21):
    n[x] = n.get(x - 1, 0) + (n.get(x // 2, 0) if x % 2 == 0 else 0)
print(n[20])
```

## Решение 2. Полностью кодом

Демоверсия 2027: A — прибавь 1, B — поменять местами две младшие цифры (только если цифра десятков меньше цифры единиц). Сколько программ переводят 100 в 141?

```python
def swap(x):
    s = str(x)
    return int(s[:-2] + s[-1] + s[-2])

def f(x, y):
    if x > y:
        return 0
    if x == y:
        return 1
    r = f(x + 1, y)
    if x // 10 % 10 < x % 10:
        r += f(swap(x), y)
    return r

print(f(100, 141))          # 16
```

Если команда может уменьшать число (например, «вычти 3»), условие «проскочил» не работает — тогда ограничивай длину программы или запрещай повторы чисел в траектории.

## Вариации

| Подтип | Изменение в `f` |
|---|---|
| Просто количество программ | базовая версия |
| Траектория содержит число c | `f(a, c) * f(c, b)` |
| Не содержит числа d | `if x == d: return 0` |
| Содержит c и не содержит d | оба приёма сразу |
| Сколько **различных результатов** у программ длины k | множество: `res = {a}`, k раз `res = {cmd(x) for x in res for cmd in cmds}` |
| Команды уменьшают число | вместо `x > y` ограничивай длину программы или запрещай повтор числа |

## Ловушки

- Обязательные и запрещённые числа: `f(a, c) * f(c, b)` и `return 0` для запрещённого.
- «Программа» без команд при a = b тоже считается — `return 1`.
- Без `@lru_cache` на больших диапазонах (от 1 до 1000 с двумя командами) рекурсия считает очень долго.
