# Задание №8 — «Словарь всех слов на свете»

Нора: **ЕГЭ: код решает** · балл: 1 · на экзамене: 3–5 минут.
Что нужно из курса: `itertools.product`, `permutations`, `enumerate`, строки.

## Суть

Комбинаторика: из набора букв составляют «слова» заданной длины с ограничениями (буква не первая, ровно две Т, нет двух гласных подряд…). Нужно посчитать слова или найти номер слова в алфавитном списке.

## Как это звучит в КИМ

«Все пятибуквенные слова из букв А, К, Ц, Е, Н, Т записаны в алфавитном порядке и пронумерованы. Под каким номером стоит первое слово с чётным номером, которое не начинается с А, Е или К и содержит хотя бы одну Т?»

## Теория

| Что нужно | Инструмент |
|---|---|
| буквы могут повторяться | `product('АБВ', repeat=5)` |
| все буквы разные | `permutations('АБВГД', 5)` |
| алфавитный порядок | `product(sorted('АКЦЕНТ'), repeat=5)` — порядок выдачи совпадает с алфавитным |
| номер слова с 1 | `enumerate(..., 1)` |

Из кортежа букв слово собирается так: `''.join(t)`.

Перебор быстрый: 6⁵ = 7776 слов, даже 8⁸ ≈ 16 млн — Python справится за десяток секунд.

## Решение 1. Полу-ручное: формула + проверка кодом

Простые счётные задачи решаются по правилу произведения. Пример: 4-буквенные слова из Л, Е, Т, О, где Е встречается хотя бы раз. Всего 4⁴ = 256 слов, без Е — 3⁴ = 81, значит с Е — 256 − 81 = **175**. Код за 3 строки подтверждает:

```python
from itertools import product
print(sum('Е' in w for w in product('ЛЕТО', repeat=4)))
```

Для «номера в списке» помогает мысль: алфавитный список — это числа в системе счисления с основанием «сколько букв». Слово `КААА` из букв `АКО` — это 1000₃ = 27, а номер на 1 больше: 28.

## Решение 2. Полностью кодом

```python
from itertools import product

for i, t in enumerate(product(sorted('АКЦЕНТ'), repeat=5), 1):
    w = ''.join(t)
    if i % 2 == 0 and w[0] not in 'АЕК' and 'Т' in w:
        print(i)
        break
```

Ответ демоверсии 2027 — `3914`. Первая строка вывода, если убрать условие, — `1 ААААА`: так проверяешь, что нумерация совпадает с условием.

Слова с разными буквами и запретами (мягкий знак не в начале и не после гласной):

```python
from itertools import permutations
k = 0
for t in permutations('ТЬЮРИНГ', 6):
    w = ''.join(t)
    if w[0] != 'Ь' and 'ЮЬ' not in w and 'ИЬ' not in w:
        k += 1
print(k)          # 3120
```

## Вариации

| Подтип | Инструмент |
|---|---|
| Номер слова в алфавитном списке | `enumerate(product(sorted(...)), 1)` |
| Слова с условиями (сколько всего) | `product` или `permutations` + `sum(... for ...)` |
| «Числа» в системе счисления (пятеричные шестизначные числа, где…) | цифры — те же буквы; первая цифра не 0: `w[0] != '0'` |
| Все буквы различны / каждая ровно раз | `permutations` |
| Запреты на соседей (две гласные рядом) | замени гласные одной буквой и ищи `'ГГ' in w` |

Если слов слишком много (10 букв по 10 позиций), посчитай по правилу произведения, а код проверь на маленькой версии задачи.

## Ловушки

- `product('ЛЕТО')` без `sorted` выдаёт слова в порядке букв строки, а не по алфавиту.
- «Ровно две буквы А» — `w.count('А') == 2`, «не более двух» — `<= 2`.
- Шаблон «гласная рядом с гласной»: проверяй пары `w[i] + w[i+1]` в цикле или через замену всех гласных на одну букву: `w2 = w.translate(str.maketrans('ИЮ', 'ГГ'))`, потом `'ГГ' in w2`.
