# Задание №11 — «Пароль на сколько байт»

Нора: **ЕГЭ: почти без кода** · балл: 1 · на экзамене: 4–6 минут.
Что нужно из курса: `math.ceil`, `math.log2`, циклы.

## Суть

Номера, пароли, идентификаторы хранят посимвольно: каждый символ — одинаковым минимальным числом бит, а каждый номер целиком — целым числом байт. Найти объём памяти, длину пароля или мощность алфавита.

## Теория: две ступени округления

1. Символ: i бит, где 2^i ≥ мощность алфавита. `i = ceil(log2(N))`.
2. Номер из L символов: L·i бит → **вверх** до целых байт: `ceil(L * i / 8)`.
3. Всего: байт на номер × количество номеров.

Пример: 26 заглавных латинских + 10 цифр = 36 символов → 6 бит. Пароль из 15 символов: 90 бит → 12 байт (96 бит).

## Решение 1. Ручное

Демоверсия 2027: серийный номер — 157 символов, на 12 450 номеров отведено не больше 955 Кбайт. Максимальная мощность алфавита?

- На один номер: 955 · 1024 / 12 450 ≈ 78,5 → не больше 78 байт = 624 бита.
- На символ: 624 / 157 ≈ 3,97 → не больше 3 бит.
- 3 бита — это 2³ = **8** символов.

## Решение 2. Кодом: перебор ответа

Когда условия запутанные, проще перебрать ответ и проверить его «в лоб»:

```python
from math import ceil, log2

best = 0
for N in range(2, 10000):                       # мощность алфавита
    i = ceil(log2(N))                           # бит на символ
    per_id = ceil(157 * i / 8)                  # байт на номер
    if per_id * 12450 <= 955 * 1024:
        best = N
print(best)                                     # 8
```

Тот же приём — для «наименьшей длины пароля» или «наибольшего числа пользователей»: перебери кандидатов и проверь по формулам из условия.

## Вариации

Формула одна: байт на запись = `ceil(длина * ceil(log2(N)) / 8)`. Меняется неизвестное:

| Ищут | Что перебирать |
|---|---|
| объём памяти | ничего — просто считай |
| мощность алфавита | N, проверяй ограничение на память |
| длину номера | L |
| число пользователей | количество записей |
| байты на «дополнительные сведения» | общий объём на одного − байты на номер |

Если запутался — перебирай неизвестное и проверяй условие кодом, как в решении 2.

## Ловушки

- Округлять до байт нужно **номер целиком**, а не каждый символ.
- Мощность алфавита: «все десятичные цифры и 1200 иероглифов» = 1210.
- Кбайт — это 1024 байта; «не более 955 Кбайт» — неравенство нестрогое.
- `log2` для степеней двойки даёт целое: `ceil(log2(8)) = 3` — так и надо.
