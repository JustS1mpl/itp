# Задание №15 — «Формула, которая всегда права»

Нора: **ЕГЭ: код решает** · балл: 1 · на экзамене: 4–8 минут.
Что нужно из курса: логика из №2, `all`, `for`, `%`, `&`.

## Суть

Дано логическое выражение с параметром A. Нужно найти наибольшее или наименьшее A, при котором выражение истинно **при любом** x (иногда при любых x и y). Бывает четыре вида:

| Вид | Что внутри | В Python |
|---|---|---|
| делимость | ДЕЛ(x, A) — «x делится на A» | `x % A == 0` |
| отрезки | x ∈ P, x ∈ A | `p1 <= x <= p2` |
| побитовое И | x & 25 ≠ 0 | `x & 25 != 0` |
| неравенства | (x + 2y < A) | как есть |

## Теория: проверка «при любом x»

«Истинно при любом x» = «нет ни одного x, при котором ложно». В коде это `all(... for x in range(...))`. Диапазон x бери с запасом: для делимости — до нескольких тысяч, для битовых — до 1024 (или 2¹⁰ больше самых больших чисел из условия).

## Решение 1. Полу-ручное: рассуждение + короткая проверка

Демоверсия 2027: ДЕЛ(x, A) ∨ ((x ∈ [70; 90]) → ¬ДЕЛ(x, 22)), наибольшее A.

Выражение может быть ложным только когда x ∈ [70; 90] и x делится на 22, то есть x = 88. Значит, достаточно, чтобы 88 делилось на A. Наибольшее такое A — **88**. Код подтверждает, что при A = 88 всё истинно:

```python
A = 88
print(all(x % A == 0 or not (70 <= x <= 90) or x % 22 != 0 for x in range(1, 10000)))
```

## Решение 2. Полностью кодом: перебор A

```python
def ok(A):
    for x in range(1, 10000):
        b = 70 <= x <= 90
        if not (x % A == 0 or (not b or x % 22 != 0)):
            return False
    return True

for A in range(1000, 0, -1):            # наибольшее — идём сверху вниз
    if ok(A):
        print(A)                        # 88
        break
```

Для «наименьшего A» перебирай снизу вверх.

### Отрезки: A — тоже отрезок

«Найдите наименьшую длину отрезка A, чтобы выражение было истинно при любом x». A задаётся двумя концами — перебирай их по «интересным точкам»: концам данных отрезков (и чуть сдвинутым). Проще всего перебрать x с шагом 0,5 или умножить все числа на 2 и работать с целыми, а концы A брать из списка концов P и Q.

```python
P, Q = (10, 30), (25, 50)                       # пример из типовой задачи
pts = sorted({*P, *Q})
best = None
for a1 in pts:
    for a2 in pts:
        if a1 > a2: continue
        if all(((P[0] <= x <= P[1]) <= (Q[0] <= x <= Q[1])) or (a1 <= x <= a2)
               for x in [t / 2 for t in range(0, 200)]):
            best = min(best or 10**9, a2 - a1)
print(best)
```

## Вариации

| Подтип | Как узнать | Приём |
|---|---|---|
| Делимость | ДЕЛ(x, A) | перебор A, внутри `all` по x |
| Побитовое И | `x & 25` | x до 1024 (больше всех масок), `(x & A) != 0` — **скобки обязательны** |
| Отрезки | x ∈ P, длина отрезка A | концы A — из концов P и Q; x перебирай с шагом 0,5 или умножь всё на 2 |
| Неравенства с x и y | `(x + 2y < A)` | два цикла по x и y до 100–200, перебор A |
| «Тождественно ложно» | вместо «истинно» | проверяй `not any(...)` |

Для неравенств шаблон такой:

```python
for A in range(1, 1000):
    if all((x + 2*y < A) or (y > x) or (x > 30)
           for x in range(1, 200) for y in range(1, 200)):
        print(A); break
```

## Ловушки

- Импликация «→» в коде — `not a or b` (или `a <= b` для чисел 0/1). Пропущенный `not` — частая потеря балла.
- `x & 25 != 0` в Python читается как `x & (25 != 0)`! Пиши `(x & 25) != 0`.
- «Натуральное A» — начинай с 1, а не с 0 (на 0 делить нельзя).
