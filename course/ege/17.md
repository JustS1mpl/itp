# Задание №17 — «Пары в потоке чисел»

Нора: **ЕГЭ: код решает** · балл: 1 · на экзамене: 5–8 минут.
Что нужно из курса: чтение файла, списки, `zip`, `min/max`, `%`.

## Суть

В файле — последовательность целых чисел, по одному в строке. Рассматриваются **пары** (иногда тройки) соседних элементов. Нужно найти количество пар с условием и, например, максимальную сумму среди них. Условие обычно ссылается на всю последовательность: «минимальный элемент», «максимальный элемент, оканчивающийся на 3», «среднее арифметическое».

## Как это звучит в КИМ

«Определите количество пар последовательности, в которых остаток от деления на 33 хотя бы одного из элементов равен минимальному элементу последовательности. В ответе запишите количество найденных пар, затем максимальную из сумм элементов таких пар».

## Теория

- Прочитать числа: `a = [int(s) for s in open('17.txt')]`.
- Соседние пары: `zip(a, a[1:])` даёт `(a[0], a[1]), (a[1], a[2]), …`. Тройки: `zip(a, a[1:], a[2:])`.
- «Хотя бы один» — `or`, «ровно один» — `(x % 33 == m) != (y % 33 == m)` (сравнение двух bool работает как «исключающее или»).
- «Оканчивается на 3» — `abs(x) % 10 == 3` (на случай отрицательных), «трёхзначное» — `100 <= abs(x) <= 999`.

## Решение 1. Полу-ручное: Excel/Calc

Числа в столбце A. В B1 формула для пары `(A1, A2)`: `=ЕСЛИ(ИЛИ(ОСТАТ(A1;33)=МИН(A:A);ОСТАТ(A2;33)=МИН(A:A));A1+A2;"")`, протянуть до предпоследней строки. Ответ — `=СЧЁТ(B:B)` и `=МАКС(B:B)`. Работает, но формулы длинные, а ошибиться с диапазонами легко — поэтому на экзамене чаще пишут код.

## Решение 2. Полностью кодом

```python
a = [int(s) for s in open('17.txt')]
m = min(a)
sums = [x + y for x, y in zip(a, a[1:]) if x % 33 == m or y % 33 == m]
print(len(sums), max(sums))
```

Ответ демоверсии 2027 — `622 174933`.

Шаблон на любые условия:

```python
a = [int(s) for s in open('17.txt')]
M = max(x for x in a if abs(x) % 10 == 3)          # «из всей последовательности»
k, best = 0, -10**9
for x, y in zip(a, a[1:]):
    if (abs(x) % 10 == 3) + (abs(y) % 10 == 3) == 1 and (x + y) ** 2 <= M ** 2:
        k += 1
        best = max(best, x + y)
print(k, best)
```

`(условие1) + (условие2) == 1` — «ровно один элемент пары подходит»: `True` считается как 1.

## Вариации

| Подтип | Как |
|---|---|
| Пары соседей | `zip(a, a[1:])` |
| Тройки соседей | `zip(a, a[1:], a[2:])` |
| Любые пары (не соседние) | два цикла `for i … for j in range(i+1, n)`; для больших файлов — подумай о счёте по остаткам |
| Модули, квадраты, произведения в ответе | меняется одна формула при подсчёте |
| Номера элементов в условии | `enumerate(a, 1)` |
| «Тройка — стороны прямоугольного треугольника» | `s = sorted(t); s[0]**2 + s[1]**2 == s[2]**2` |

Порядок в ответе («сначала количество, потом…») читай внимательно.

## Ловушки

- Пар на одну меньше, чем чисел. `zip` сам останавливается вовремя.
- Отрицательные числа: `-13 % 10` в Python — `7`. Для последней цифры бери `abs(x) % 10`.
- Если в файле первая строка — количество чисел, не включай её в последовательность.
