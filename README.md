# ИТП («И так Пайтон»)

Одностраничное приложение для изучения Python в стиле Duolingo. Результат сборки — один HTML-файл `ИТП.vX.Y.Z.html`, всё внутри (Python в браузере через Pyodide, шрифт, эмодзи), интернет не нужен.

## Как собрать

1. Скачать ядро Pyodide 0.29.3 (`pyodide-core-0.29.3.tar.bz2` со страницы релизов github.com/pyodide/pyodide) и распаковать так, чтобы получилась папка `pyo/pyodide/` (в ней `pyodide.asm.wasm`, `pyodide.asm.js`, `python_stdlib.zip`, `pyodide-lock.json`, `pyodide.js`). Папка `pyo/` в git не хранится.
2. Запустить `./mk.sh`. Он делает три шага: `python3 build.py` (темы → `out.html`), `cp out.html base43.html` (обязательно, иначе `build5.py` возьмёт устаревшую базу), `python3 build5.py` (интерфейс v5, Pyodide → `out5.html`).
3. Номер версии задаётся переменной `VER` в `build5.py`. Готовый файл переименовать в `ИТП.v<версия>.html`.

## Что где лежит

| Путь | Назначение |
|---|---|
| `build.py`, `p4*.py`, `orig.html` | сборка базы (темы, история патчей) |
| `build5.py`, `msgs.py` | сборка интерфейса v5, подсветка функций |
| `content.py`, `c_t*.py`, `c_intro.py`, `dsl.py` | содержание: темы Python (`c_t*`); новые темы Python добавляют в конец списка в `content.py` |
| `v5/` | интерфейс: `a_*.js` (логика и интерфейс), `v5*.css`, `py/` (запуск Python) |
| `assets/` | шрифт и пакет эмодзи (base64) |
| `docs/` | промт для нейросетей: как добавлять и менять темы |
| `tests/` | проверки (нужен Playwright). Запускать из корня репозитория; `xc5.py` прогоняет все примеры, вопросы и задачи в Pyodide, `mig.py` проверяет перенос старых сохранений, остальные скрипты проверяют экраны. `h.py` ожидает папку `sk/` (Skulpt) и путь к Chromium, в репозитории их нет |

## Правила проекта

Полный список правил (теория подробно с выводом, задания только на объяснённый материал, подсказки должны помогать и т. д.) и порядок добавления тем описаны в `docs/prompt_for_ai_v6.4.1.md`.
