# ИТП («И так, программирование»)

Одностраничное приложение для изучения Python в стиле Duolingo для учеников 15–16 лет. ИТП расшифровывается как «И так, программирование». Результат сборки — один HTML-файл `ИТП.vX.Y.Z.html`, всё внутри (Python в браузере через Pyodide, шрифт, эмодзи), интернет не нужен. Сторонние библиотеки Python (numpy, pandas, matplotlib и др.) в файл не входят: компилятор докачивает их с CDN Pyodide или PyPI, когда программа их импортирует и есть интернет.

## Как собрать

1. Скачать ядро Pyodide 0.29.3 (`pyodide-core-0.29.3.tar.bz2` со страницы релизов github.com/pyodide/pyodide) и распаковать так, чтобы получилась папка `pyo/pyodide/` (в ней `pyodide.asm.wasm`, `pyodide.asm.js`, `python_stdlib.zip`, `pyodide-lock.json`, `pyodide.js`). Папка `pyo/` в git не хранится.
2. Запустить `./mk.sh`. Он делает три шага: `python3 build.py` (темы → `out.html`), `cp out.html base43.html` (обязательно, иначе `build5.py` возьмёт устаревшую базу), `python3 build5.py` (интерфейс v6, Pyodide → `out5.html`).
3. Номер версии задаётся переменной `VER` в `build5.py` (сейчас 6.8.4). Готовый файл переименовать в `ИТП.v<версия>.html`.

## Что где лежит

| Путь | Назначение |
|---|---|
| `build.py`, `p4*.py`, `orig.html` | сборка базы (темы, история патчей) |
| `build5.py`, `msgs.py` | сборка интерфейса, подсветка функций |
| `content.py`, `c_t*.py`, `c_intro.py`, `dsl.py` | содержание: темы Python (`c_t*`); новые темы Python добавляют в конец списка в `content.py` |
| `v5/` | интерфейс: `v6.css` (дизайн-система v6: токены и компоненты для обеих тем), `a_ui.js` (шапка, Путь, практика, профиль, настройки), `a_screens.js` (уроки, редактор, словарь, окна), `a_boot.js` (вступление: заставка, терминал, синий экран с осколками, звуки вступления), `a_sound.js` (звуковой дизайн: синтез Web Audio, без файлов), `a_core.js` и остальные `a_*.js` (логика), `py/` (запуск Python) |
| `assets/` | шрифт, пакет эмодзи (base64), настроения кролика `assets/mascot/` (WebP, встраиваются при сборке) |
| `sounds-preview.html` | страница для прослушивания звуков (только для проверки, в приложение не входит; собирается из `v5/a_sound.js` скриптом `tests/mk_preview.py`) |
| `docs/` | промт для нейросетей: как добавлять и менять темы |
| `tests/` | проверки (нужен Playwright). Запускать из корня репозитория; `xc5.py` прогоняет все примеры, вопросы и задачи в Pyodide, `mig.py` проверяет перенос старых сохранений, `nick6.js` проверяет фильтр ника из вступления на списках плохих ников и обычных имён (запуск: `node tests/nick6.js`, браузер не нужен), `ui6.py` проходит путь ученика по интерфейсу v6 (нажатия, ввод, проверка кода), `sound6.py` проверяет поведение звука в приложении (первое касание, выключатели, заблокированный звук, скрытая вкладка, момент срабатывания; нужен numpy), `sound_wav.py` рисует каждый звук без динамиков в WAV и меряет пик, нули на краях, длительность, спектр и громкость (нужны numpy, scipy, matplotlib; `tests/mk_preview.py` собирает `sounds-preview.html`, страницу для прослушивания), остальные скрипты проверяют экраны. `h.py` ожидает папку `sk/` (Skulpt) и путь к Chromium, в репозитории их нет |
