# ИТП («И так Пайтон»)

Одностраничное приложение для изучения Python в стиле Duolingo плюс раздел подготовки к ЕГЭ по информатике (задания №1–6). Результат сборки — один HTML-файл `ИТП.vX.Y.Z.html`, всё внутри (Python в браузере через Pyodide, шрифт, эмодзи), интернет не нужен.

## Как собрать

1. Ядро Pyodide 0.29.3 скачивается командой `./fetch_pyodide.sh` (папка `pyo/pyodide/`: `pyodide.asm.wasm`, `pyodide.asm.js`, `python_stdlib.zip`, `pyodide-lock.json`, `pyodide.js`). Папка `pyo/` в git не хранится.
2. Запустить `./mk.sh`. Он делает три шага: `python3 build.py` (темы Python и ЕГЭ → `out.html`), `cp out.html base43.html` (обязательно, иначе `build5.py` возьмёт устаревшую базу), `python3 build5.py` (интерфейс v5, Pyodide → `out5.html`).
3. Номер версии задаётся переменной `VER` в `build5.py`. Готовый файл переименовать в `ИТП.v<версия>.html`.

Всю цепочку (скачивание, сборка, проверки) запускает `./check.sh`. С аргументом `full` добавляется обход всех островков через интерфейс (около 15 минут). Нужны `python3`, пакет `playwright` (`pip install playwright`) и Chromium.

## Что где лежит

| Путь | Назначение |
|---|---|
| `build.py`, `p4*.py`, `orig.html` | сборка базы (темы, история патчей) |
| `build5.py`, `msgs.py` | сборка интерфейса v5, подсветка функций |
| `content.py`, `c_t*.py`, `c_e*.py`, `c_intro.py`, `dsl.py` | содержание: темы Python (`c_t*`) и задания ЕГЭ (`c_e01`…`c_e06`) |
| `exam/` | данные заданий ЕГЭ (`taskNN.json`, `q5.json` — параметры примеров №5) |
| `v5/` | интерфейс: `a_*.js` (логика, генераторы `a_gen*.js`, окно черепахи `a_turtle.js`), `v5*.css`, `py/` (запуск Python и модуль turtle) |
| `assets/` | шрифт и пакет эмодзи (base64) |
| `docs/` | промт для нейросетей: как добавлять и менять темы |
| `tests/` | проверки (нужен Playwright, запускать из корня репозитория после сборки). `xc5.py` прогоняет все примеры, вопросы и задачи в Pyodide; `cpython_check.py` сверяет их с настоящим CPython; `gen_fuzz.py` проверяет генераторы заданий ЕГЭ; `state_fuzz.py` проверяет устойчивость к повреждённому сохранению; `crawl.py` проходит все островки через интерфейс. Остальные скрипты проверяют отдельные экраны. `h.py` — общий помощник, ожидает папку `sk/` (Skulpt) в корне |

## Правила проекта

Полный список правил (теория подробно с выводом, задания только на объяснённый материал, подсказки должны помогать и т. д.) и порядок добавления тем описаны в `docs/prompt_for_ai_v5.4.0.md`.
